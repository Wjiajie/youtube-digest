# 按节点的视频候选检索

更新：2026-09-10。P7 内部服务端切片，起点 `1de87c3`；不是用户可用的推荐功能，也没有上线或发起真实供应商请求。

## 当前实现

已确认路径中的学习节点，可以作为检索来源。内部运行器接收一份合法 BlueprintSnapshot 和其中的节点 ID，仅使用该节点的标题、描述构造长度受限的查询；不会发送整份蓝图、其他目标或完成依据，不会修改节点或资源绑定。

服务端调用者仍必须从当前已认证账号读取最新快照。本模块只检查快照结构和节点是否存在，不能凭传入对象证明账号所有权、用户确认或数据仍为最新；接入页面前必须补齐这些保护。

流程分为三层：

1. **发现**：YouTube 搜索一页，最多十条结果；去重后查一次详情，只接受搜索确实返回的 ID，保留搜索顺序。
2. **可用性筛选**：排除非公开、未处理完成、直播／预告、地区不允许、年龄限制、超出时长，以及不满足用户明确时间要求的内容。基础知识视频不会仅因年代久远被淘汰；不可嵌入不等于不能在 YouTube 学习。
3. **原生字幕证据**：只对剩余候选的前三条请求字幕。无字幕或处理中不会用第四条自动补位，不轮询、不启动自动转录。实际语言与偏好不符时明确标记；不接受语言回退时，该项不进入后续内容匹配。

搜索语言是偏好而非严格过滤。地区与上传状态等 API 元信息不保证用户当下能播放视频，也不证明内容适合该学习目标。相关定义见 [YouTube 搜索](https://developers.google.com/youtube/v3/docs/search/list)和[视频元信息](https://developers.google.com/youtube/v3/docs/videos)。

结果保留蓝图 ID／版本、节点 ID、检索开始时间、被筛除原因、未检查的候选及可能已发出的请求。候选标为“尚未内容匹配”，**搜索顺序第一不等于最佳推荐**。观看、点赞、评论数按原始十进制字符串保留；缺失为未知，不设为零、不换算质量分、不读取已废弃的收藏数。

## 字幕与失败边界

Supadata 请求固定为 `mode=native,text=false`。直接字幕、后台任务 ID、无字幕、限流、超时及不可用分别保留。单独的任务读取能力只读取既有任务，不重启转录；完成内容按官方顶层结构解析，保留实际字幕语言和毫秒时间戳。参见[字幕请求](https://docs.supadata.ai/api-reference/endpoint/transcript/transcript)和[任务结果](https://docs.supadata.ai/api-reference/endpoint/transcript/transcript-get)。

供应商适配器固定外部来源、不跟随重定向、不自动重试。每个 HTTP 请求的十秒期限覆盖读取响应体，解码后的响应上限为 1 MiB；取消会终止等待和后续调用，迟到结果不会被采用。错误只返回分类，不回传供应商正文、密钥或取消原因。过大的字幕当前返回不可用，不静默截断成“完整字幕”。

正常一次发现最多一次搜索、一次详情和三次原生字幕请求。请求记录是保守的“可能已发出”记录，**不是账单或精确计费证据**。即使取消，外部服务也可能已经处理并计费；原生字幕也不等于永久免费。账号额度、租约、重复请求去重、持久检查点与费用结算尚未接入。

## 模块与验证

- [来源绑定与筛选](../apps/web/src/lib/resources/discovery.ts)：通用路径节点与候选证据之间的边界。
- [供应商适配](../apps/web/src/lib/resources/provider.ts)及[受限 HTTP 读取](../apps/web/src/lib/resources/provider-http.ts)：真实服务协议，不读取环境或记录正文，凭据由未来服务端调用者显式提供。
- [运行器行为测试](../apps/web/src/lib/resources/discovery.test.ts)、[供应商边界测试](../apps/web/src/lib/resources/provider.test.ts)与[本地 HTTP 集成](../apps/web/src/lib/resources/discovery.integration.test.ts)：固定响应，不调用真实 API、不使用真实密钥。

本批 57 项测试通过，包含真实适配器经过本地 HTTP 的完整搜索／详情／原生字幕链路、显式任务读取、限流、流式响应取消、语言回退、请求上限及来源不变。集成验证发现并修复可选统计字段缺失导致整个视频被误丢弃的问题；缺失统计不会再让有效视频消失。

复现：`bash scripts/with-m1-runtime.sh npx vitest run apps/web/src/lib/resources`。

## 后续交付门槛

- 资源匹配 Skill：只从这批真实候选选择，依据节点完成标准和字幕内容解释适配理由；最多一个默认与两个备选，也允许无合格结果。描述和字幕中的指令不能成为系统指令。
- 云端运行：已认证所有权、当前蓝图版本、账号次数／费用、持久任务来源与受控恢复；任何任务读取都不能仅凭客户端提交的 jobId 放行。采用前重新检查来源和可用性。
- 双主题界面：展示候选、未知／失败状态与推荐理由；明确采用／替换／移除，不直接由 Agent 修改正式路径，再接入扩展学习工作台。
- 真实质量：受控真实 API 验证、跨领域评测、真实成本与服务限额、字幕访问和缓存合规检查。离线夹具只证明协议与行为，不证明推荐质量或真实可播放性。

当前没有开放路由、客户端导入、云端写入、缓存或新环境变量。既有学习会话和提案链路不变；托管版本、正式 3D 美术与完整 P1–P9 门槛仍按[执行路线](execution-roadmap.md)保留。
