# 目标澄清工作台

固定点：`92516bd`。本批把[云端会话](agent-clarification-sessions.md)接入真实 Web 入口：从不完整想法出发，对话、修改工作摘要，再由用户明确保存或确认目标定义。它不是正式路径生成，也不是托管发布或真实模型质量验收。

## 用户体验与顶层设计

- “我的目标定义”同时提供对话梳理与直接填写入口。访问新建页不写数据；用户点击开启后才保存空白私人草稿并创建会话。创建不调用模型；重复提交同一请求恢复原记录。
- 工作台由对话、可直接修改的工作摘要、方向准备度三部分构成。赛博主题使用控制台式编号、强调线和深色面板；东方主题使用信笺边线、印章、衬线标题与纸面层次。同一套业务逻辑和语义 Token 驱动两种表现。
- 每次回答明确发起独立请求，展示实际保存的问题、回答、建议与原话依据。没有伪造的思考过程、自动续写或模拟流式文本。暂停、待补充和待审阅分开表达。
- 工作摘要与已保存 Goal Brief 分开。用户修改字段后，须先点击“更新工作摘要”；随后可“保存草稿”或勾选核对声明并“确认这版目标定义”。完整度只表示必要信息是否齐全，不代表目标质量或成功保证。
- 保存会结束会话，不会自动生成路径。用户从定义页另行发起规划；最终正式蓝图仍需要提案确认。历史会话不冒充当前定义的确认状态。
- 澄清生成开关关闭时仍能阅读、手动编辑并保存。源定义已确认时需先明确编辑，才能开启新澄清；源定义变化后旧会话只读。成功回合达窗口上限时引导明确保存检查点，再开新会话，不偷偷截断历史。

## 恢复、身份与隐私

- 生成通过独立 HTTP 请求，读取与取消使用独立 Server Actions，避免长推理把取消排在同一动作队列之后。
- 回合 ID 写入恢复 URL，不放入回答正文。未知发送结果只允许核对原回合或取消，不自动重发。未查到记录不等于在途请求没有执行；不能用此信号自动生成第二轮。
- 修改与保存保留同一请求及 mutation ID，响应不确定时明确核对原提交，不创建新的写入意图。未发送文本与尚未应用的字段目前只保存在页面内存，离开页面不保证恢复；有未确认提交时明确提示不要关闭。
- 刷新不静默覆盖用户正在编辑的内容。版本冲突保留本机文字，并提供查看云端摘要、保留本机文字重新核对、放弃本机修改的明确选择。
- 操作重新验证 Cookie 身份，并绑定当前账号及会话；不能通过替换回合 URL 读取或取消另一会话。账号切换或身份失效隐藏私人内容，迟到结果不得跳回原账号会话。
- 客户端只接收需要展示的摘要、轮次、Skill 版本号和原话依据，不发送完整 Skill 指令、重复来源／问答历史、私有租约或密钥。
- AI 叙述使用官方 AI Elements 消息组件的最小改造子集与 Streamdown；限定安全文本元素，不允许模型生成外链、远程图片或 HTML。字段、用户回答与原话依据始终按普通文本显示。改造来源采用 [Apache-2.0 许可及修改说明](licenses/ai-elements-Apache-2.0.txt)。

## 技术与运行边界

Next.js RSC 负责认证与初始读取，React 客户端组件负责交互；服务端工作台模块负责明确创建、最小投影及会话绑定。沿用现有 Supabase Auth、RLS、会话 RPC、AI SDK 与 DeepSeek 适配，不增加数据库迁移。

生成路由要求同源 Cookie、严格参数与匹配账号；请求体最多 64 KiB，足以容纳 8000 字中文回答。读取有五秒期限，拒绝乱码与超限输入。Auth 临时故障与确定身份失效分开返回。固定澄清 Skill 随生产服务端产物追踪，不打包到浏览器。

`BLUEPRINT_CLARIFICATION_ENABLED` 默认关闭；须配置独立工作密钥及现有服务端模型密钥。Node 只负责推理，用户 JWT 与独立凭据转交真实 Edge，由 Edge 验证身份并执行受控特权写入。不开启开关、不授予次数，就不会因访问页面产生模型费用。

## 验收记录

500 项应用测试／51 文件、41 项 Edge 处理器测试、四工作区类型检查、既有账号迁移契约、向导和扩展构建／安全检查通过。新增浏览器测试另通过严格类型检查；独立分轴复核将在实现提交后补充。

真实本地 Auth → 生产 Web → 数据库 → Edge → 官方 DeepSeek SDK → 明确确认的两条主题旅程通过，仅替换测试进程中的供应商 HTTP 响应。覆盖新建 GET 不创建数据、显式空白草稿、零次数拒绝、一次生成、独立标签读取原回合、直接编辑、确认定义而不改变蓝图，以及真实 HTTP 同源／账号／参数／超大中文请求检查。测试自建账号已退出并删除。

两套主题均通过账号保存后跨页读取，并在 1440／320 像素布局截图中核对，无水平溢出。首轮测试只选择但未保存主题，导航后回到赛博，虽业务通过却不能算东方证据；截图复核发现后修正测试，重新运行及人工看图才计入双主题结果。含恶意外链／图片的测试模型叙述没有生成对应导航、图片或外部请求；浏览器接收内容未发现所检查的完整 Skill、哈希或工作密钥。没有把这些有限检查当成所有隐私或无障碍问题均已穷尽。

已通过的行为检查包括：会话隔离、创建途中账号变化、真实本地账号明确创建／保存、丢失响应保留原请求、取消不受未返回 POST 阻塞、旧快照不复活已取消回合、编辑冲突、明确核对后确认、服务关闭保留手动编辑、模型文本安全渲染、请求容量／停滞／UTF-8 与 Auth 刷新故障分类。
