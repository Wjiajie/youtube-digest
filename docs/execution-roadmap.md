## 产品北极星

Blueprint 是一个 **Agent 辅助的个人目标系统**。用户描述长期目标，Agent 帮助澄清约束、构建可审阅的路径图，并为适合学习的节点寻找 YouTube 视频。用户拥有最终蓝图，可以接受、替换或拒绝 Agent 的建议。

YouTube 是现阶段最重要的学习资源载体，不是产品边界。完整闭环是：

```text
长期目标
  → Agent 辅助构建路径
  → 用户审阅并拥有蓝图
  → 适合学习的节点绑定可替换的 YouTube 视频
  → 观看、理解与记录
  → 基于学习证据复盘
  → Agent 提议调整路径
```

Blueprint 近期不扩张为自动替用户执行现实世界任务的通用 Agent，也不以团队协作、排行榜或完整游戏经济为目标。当前先把个人目标规划、学习和复盘闭环做深。

## 历史基线：`2.0.0` 本地原型

### 已实现能力

- Chrome Manifest V3 扩展，包含 3D 蓝图主页、目标路径页、设置页和 YouTube 学习侧边栏。
- 科幻、赛博朋克、武侠和现代都市四种视觉主题。
- 以 Markdown 表达目标、里程碑和学习节点的分层蓝图。
- Agent 生成完整蓝图提案，用户预览确认后才持久化；并发写入有版本冲突保护。
- Windows Native Agent Host、Pi Agent Core 和 DeepSeek V4 Flash 组成的本地 Agent 边界。
- YouTube 原生字幕获取、视频概览、双语字幕、选文讲解和时间戳笔记。
- 自动化测试基线：2026-08-25 执行 `npm test`，63 项测试全部通过。

历史源码和当时测试保存在 Git 标签 `v2.0.0`；当前[系统架构](architecture.md)和 [UI/UX 设计](ui-ux-design.md)已经切换为 M1 口径。

### 主要缺口

- 蓝图、设置、会话和学习数据保存在 Chrome 本地存储中，没有账号、服务器数据或跨设备同步。
- Agent 依赖 Windows 本地 Host 和用户自己的 DeepSeek Key，安装与首次使用门槛较高。
- 3D 场景仍是基础几何体、硬编码灯光和粒子组成的演示级表达，主题与世界内容结合较弱。
- 蓝图规划提示只规定了基本工具顺序和提案规则，没有目标澄清方法、路径质量标准、视频检索工具或固定评测集。
- Agent 无浏览器和任意网络工具，不能验证它写入的 YouTube 视频是否真实、合适或具备可用字幕。
- 学习侧边栏仍保留旧 YouTube Digest 的部分视觉和交互心智，缺少目标上下文、学习进度和明确的返回路径。
- 扩展协调层、3D 页面和侧边栏由大型原生 JavaScript 文件承担，未来 Web 与扩展共享领域逻辑和组件的成本较高。

## 目标产品与系统边界

目标交付形态为 **Web 主站 + YouTube 扩展**：

```text
Web 主站 ─────────┐
                  ├─ 账号、云数据、目标与学习服务
YouTube 扩展 ─────┘           │
                              ├─ Agent / DeepSeek
                              ├─ YouTube Data API
                              └─ Supadata
```

- Web 主站承载账号、3D 蓝图、目标路径、规划师和复盘。
- 未登录访客可以体验明确标注的公开示例，创建和保存个人蓝图时登录；已有用户直接进入个人主页。示例数据与个人成果隔离。
- 扩展专注于把目标节点连接到 YouTube，并提供伴随视频的学习工作台。
- PostgreSQL 的结构化实体成为事实来源，覆盖用户、蓝图、目标、通用路径节点、资源绑定、学习会话、证据事件和复盘。路径节点至少支持学习、实践、检查点和复盘；YouTube 是可选资源绑定，不是节点本体。
- Markdown 保留为 Agent 提案、用户审阅和导出格式，不再独自承担稳定 ID 与学习进度存储。
- Web 与扩展共享同一个账号身份和云端数据，但分别维护安全会话。扩展通过 Web 授权获得自己的会话；本地存储只用于缓存、短期恢复和待同步操作。
- Agent 只能生成提案。目标路径或复盘建议必须经过用户确认，才能写入正式蓝图。
- 主题属于表现层：角色、环境、面板、排版、动效和有限构图可以改变，目标语义、证据标准、确认和返回路径保持一致。身份、成果与主题外观分离，切换主题不生成蓝图修订或重置用户历史。
- 新云端版本从空账号开始，不迁移或兼容现有 Chrome 本地数据；当前没有需要保留的真实用户数据。
- DeepSeek、YouTube Data API 和 Supadata 密钥全部保存在服务端。邀请测试阶段由平台承担额度，并设置账号级限制。
- Windows Native Agent Host 从目标方案中即时退役，不再作为新能力、迁移回退或兼容路径。相关源码只作为 `2.0.0` 历史基线，后续由新架构直接替换。

### 本次调整后的推进关系

保留 M0–M6 编号，不把设计讨论视为功能完成。M1 托管验收仍是当前工程优先项；多主题设计基础可以并行准备，并先于大规模界面开发。

1. **设计基础**：优先核查开放资产来源、许可和改造量，形成两主题风格板、全旅程关键页面、主题契约、商用品质与性能测量条件；不以付费采购作为前提。
2. **M1 验收后并行实现**：M2 通用 Agent、M3 主题装配与 3D，以及从 M5 抽出的最小成果记录。Agent 不必等全部美术完成，3D 也不依赖完整复盘。
3. **双端连续体验**：M4 的两主题学习工作台接入相同成果记录，打通首页→路径→学习/实践→记录→首页反馈；再完成 M5 全量复盘与身份积累。
4. **外部交付检查**：两主题同一核心旅程都通过美术、状态、性能、可访问性与生产可靠性验收，再进入 M6 对应范围；不把一套正式主题加一套演示皮肤称为双主题首发。

设计产物细则见 [目标 UI/UX 规划](target-ui-ux-plan.md)，不另建阶段状态源。

#### 实施边界与质量预算

- 复用 Next.js/React/TypeScript、WXT/MV3、Supabase；Web 场景采用 Three.js/React Three Fiber/Drei 与 Blender/glTF；设计系统用语义 Token、Tailwind、Radix/shadcn、Motion。版本以实际安装的锁文件为准。
- Agent 采用 AI SDK 7 与直接 DeepSeek 适配，默认 `deepseek-v4-flash`。应用控制澄清→规划→资源匹配，通用管线不硬编码职业领域；完整复盘 Skill 延后。页面关闭保存已完成检查点，返回只续未完成阶段，不建设持续后台队列。
- Vercel Node 执行推理；仅窄职责的 Supabase Edge 端点可写运行状态、缓存、额度。该端点同时校验用户 JWT 与独立服务端凭据，从已验证身份取得 owner；管理员密钥不进入 Vercel。不得扩张为任意数据库写接口，也不能直接提交正式蓝图。
- 额度预留／结算与阶段转换需原子化；过期执行租约在下次请求恢复。供应商请求执行结果不确定时保守计费，不保证网络中断后供应商绝不重复计费。

- 每次修改 Skill、模型或工具策略前后都运行同一跨领域评测，并能指出提升和退化场景。

- 增加固定目标上下文、完成依据、返回路径和继续学习入口，不复制新的播放器。
- 优化首次加载、长字幕、无字幕、请求失败、Agent 不可用和笔记保存失败的恢复路径。
- Web 与扩展共享主题契约、语义 Token、术语和状态表达；两套主题均有紧凑的学习表现，不强求共享所有 React 组件或加载完整 3D。
- 接入前置最小成果记录，确保在扩展留下的记录与 Web 首页、原路径属于同一节点，不等完整奖励体系才呈现真实积累。

### 完成门槛

- 所有推荐视频来自真实检索并通过可用性检查；字幕验证只针对排名靠前的候选执行。
- 用户能理解默认推荐的理由、查看两个备选，并主动替换、移除或暂不使用视频。
- 用户能从目标节点进入正确视频，完成一次理解或记录行为，并返回原目标路径。
- 长字幕、双语、选择讲解和笔记操作在键盘、触控和窄侧边栏中均可用。
- 错误不会丢失准确原文、用户笔记或已经完成的学习操作。
- 学习工作台不再出现与 Blueprint 主产品冲突的旧品牌、入口说明或视觉层级。
- 两主题分别通过同一学习旅程；无字幕、未绑定视频、失败、离线和权限失效都有可用状态，返回 Web 后可找到本次真实成果。

## M5：学习证据、复盘与身份积累

**状态：计划。最小成果切片依赖 M1，前置支撑 M3/M4；完整学习进度与复盘依赖 M4，Agent 复盘依赖 M2。**

### 前置最小成果切片

- 允许用户针对学习、实践、检查点或复盘节点留下真实成果，并根据完成依据明确确认状态；没有视频的节点同样有效。
- 用户在首页回看成果出处与下一步，主题变化不改变记录或确认含义；自动采集的观看行为不能直接变成掌握声明。
- 记录与首页反馈采用两主题设计，复用同一保存和恢复逻辑。最小记录为默认私人的文字和作品链接，用户明确确认；不引入图片托管、公开个人主页或社交动态。主动分享卡片仍属于后续交付。
- 验收至少完成“进入节点→记录成果→确认状态→返回首页→重新打开可追溯记录”，验证保存失败与跨主题切换不会丢失内容。

这个切片通过不代表 M5 完成；下列跨设备进度、完整复盘、奖励和导出仍分别验收。

### 用户结果

用户可以跨设备继续学习，用理解、实践和检查点证据判断真实进展，完成一次复盘；用户确认的成果同时改变路径状态和人物的长期身份表达。

### 顶层交付

- 同步播放位置、观看比例、笔记和讲解等活动，并与理解、实践、检查点和复盘证据分层展示。
- 由用户根据节点完成依据明确确认“未开始、学习中、已完成或待复习”，系统不根据观看时长自动声称掌握。
- 提供继续学习、阶段回顾、复盘摘要和复盘调整 Skill。
- Agent 只基于用户可见的学习证据提出路径调整，不根据观看时长自动声称用户已经掌握。
- 所有复盘修改继续经过预览和用户确认。
- 首版游戏化只包含检查点或阶段成果奖牌、人物挂件和用户主动生成的分享卡片；奖励主要绑定实践、检查点和有效复盘，两主题表达不同但归属一致。

### 完成门槛

- 用户在另一设备登录后能恢复最近学习位置和相关笔记。
- 用户可以完成一次阶段复盘，并看懂每条调整建议使用了哪些学习证据。
- 拒绝复盘建议不会改变现有蓝图或完成状态。
- 完成实践、检查点或复盘后，用户可以获得与证据来源一致的奖牌或人物装饰；仅观看或发布空状态不会获得核心奖励。
- 用户可以导出或删除自己的进度、笔记和复盘数据。

## M6：邀请测试与公开化准备

**状态：计划，依赖 M2 至 M5 形成完整纵向闭环**

### 用户结果

产品先从个人免费层自测切换到小范围邀请测试，观察目标澄清、路径确认、学习证据、复盘、成本与连接表现；形成数据基线后再确定数值门槛和是否扩大开放。

### 顶层交付

- 第一个外部用户进入前配置可用 SMTP、服务稳定性、隐私说明、全局预算、账号额度、并发限制和异常熔断。
- 个人自测优先使用 Supabase、Vercel 和 Supadata 免费层。用户此前给出 800 元初始预算，未确认每月持续投入；外部邀请前单独落实运行预算与人力。当前素材策略为开放资产优先、不商业购买；若未来改变采购策略，需另行明确，不把运行预算转作采购授权。
- 建立目标澄清、路径提案、资源选择、学习证据、复盘、扩展授权、同步失败和恢复事件；事件不记录目标正文、字幕、笔记或作品内容。
- 根据个人自测和首批使用数据建立基线，再决定阶段淘汰或扩大门槛，不预先用缺少证据的百分比承诺成功。
- 开放自助注册前补齐更完整的额度管理、防滥用、隐私控制、数据导出和运营监控。
- 根据邀请测试的连接数据决定是否建设面向中国大陆直连的独立部署方案。
- 验证具有清晰版权、元信息和内容访问边界的非 YouTube 学习资源适配器。
- 保持个人目标系统定位，不提前进入团队协作、通用任务执行或社交排行榜。

### 完成门槛

- 规划、资源、学习和复盘闭环已经产生可查询的真实行为与用户反馈基线，并据此记录下一阶段数值门槛。
- 公开注册的成本、服务额度、隐私说明和滥用处理方式可持续。
- 新资源适配器遵守与 YouTube 节点相同的来源透明、可替换和用户确认原则。
- 对外首发的两套主题在同一旅程、主要状态、性能和资产许可上均已验收；可商用的设计标准不等于已经允许收费或对所有地区开放。

## 跨阶段质量原则

- **用户拥有数据与决策**：Agent 提案不等于已修改，任何路径变更都必须清楚展示并由用户确认。
- **事实来源清晰**：当前 3.0 源码以结构化 PostgreSQL 数据为事实来源，Markdown 是提案审阅与导出格式；2.0 本地 Markdown 只属于历史标签。
- **失败可见且可恢复**：登录、同步、Agent、视频和字幕失败都说明原因与下一步，不伪装成功。
- **隐私最小化**：产品分析只记录必要行为事件，不记录目标正文、字幕、选文、笔记或模型密钥。
- **可访问性不是降级功能**：3D、主题和动效不能阻断键盘、触控、窄屏、减少动态效果或非 WebGL 用户。
- **质量先测量再优化**：Agent、3D 性能和学习体验都先建立基线，再用相同条件比较迭代结果。
- **主题改变表达，不改变事实**：两主题共用产品用例和验收旅程；不重置身份，不以主题术语制造新的能力等级，不用视觉效果掩盖失败。

## 关键风险

| 风险 | 当前处理方式 | 重新决策触发条件 |
| --- | --- | --- |
| 中国大陆访问国际服务不稳定 | 邀请测试仅面向可稳定访问 YouTube、Vercel 和 Supabase 的用户，不承诺境内无代理直连 | 连接失败成为主要流失原因，或准备公开注册 |
| 平台承担模型、检索和字幕费用 | 个人自测先使用免费层；800 元仅为已给出的初始预算。外部邀请前确认持续预算、账号额度、超时、并发限制和异常熔断 | 预算阻断正常自测，或单用户成本随使用持续上升 |
| Web 与扩展产生两套产品逻辑 | 共享 TypeScript 领域模型、身份和设计 Token，扩展只保留 YouTube 学习场景；Web 授权扩展但两端分别维护会话 | 同一功能在两端出现不一致行为，或授权失败成为主要流失点 |
| 多主题美术投入与核心闭环争夺资源 | 两主题各一个精修基础形象与少量预设；开放资产优先、暂不购买，统一美术指导；核查许可、编辑源与改造量后验证代表性画面；保留可操作回退 | 免费候选不能达到画面目标、改造工作量无法承担、主题需复制业务逻辑，或 3D 阻碍目标阅读与下一步行动 |
| 通用 Agent 管线在具体领域失效 | 业务代码不硬编码领域，但用跨领域固定案例持续评测目标澄清、节点结构和行动可行性 | 评测显示某类目标持续产生不可执行路径 |
| Agent 推荐错误或视频失效 | 按需真实检索，分离可用性、内容匹配、原始平台指标和编辑推荐，提供一个默认与两个备选 | 资源有效性或用户替换率显示推荐不可信 |
| YouTube 配额与派生指标政策限制可信度模块 | 只为选中学习节点按需搜索，不使用已废弃收藏数；合规审计前不展示 KOC 综合分 | 搜索配额不足以支持自测或准备引入外部评分合成 |
| 游戏化奖励诱导刷状态 | 核心奖励绑定实践、检查点和有效复盘，不绑定单纯观看、登录或空状态数量 | 行为事件增加但证据质量下降 |
| 目标和学习数据包含敏感信息 | 最小化日志和分析内容，错误追踪、评测与产品分析默认脱敏 | 引入新的第三方数据处理方或公开注册 |

## 文档维护规则

- 阶段开始、完成、暂缓或顺序改变。

## 已确认假设

- 首批用户为工作 0–3 年、有职业技能提升或转岗目标、能稳定访问 YouTube、Vercel 和 Supabase 的中文用户；当前路线不承诺中国大陆境内无代理直连。
- 个人自测优先使用 Supabase、Vercel 和 Supadata 免费层；平台承担邀请阶段调用费用的方向不变。800 元为初始预算，持续运行与人力需在实施中落实；美术当前开放资产优先、暂不商业购买。
- 首发为赛博朋克与东方山水/武侠两套完整主题，采用精品风格化制作；主题切换延续用户身份与成果，其他主题、完整捏脸和换装后续扩展。
- 每主题一个精修基础形象与少量配色/配饰预设；最小成果为默认私人的文字及作品链接，主动分享卡片后续交付。
- 阶段按完成门槛推进；在团队规模与投入时间未确定前不写死日历工期。
- 当前没有需要保留的真实用户数据，不建设旧版数据迁移或兼容能力；Windows Native Agent Host 不进入新架构。
