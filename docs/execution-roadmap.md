# Blueprint 多阶段执行路线

本文档是 Blueprint 从本地原型走向邀请制云端产品的唯一执行路线。它记录已经实现的能力、已确认但尚未实现的目标架构、各阶段的完成门槛，以及改变路线时必须保留的决策依据。

> 本文档描述未来方向时使用“目标”“计划”或“下一步”。只有状态为“已实现”的内容才代表当前产品能力。

- **暂缓**：曾被提出，但不在当前产品顺序中；重新启动前需要新的产品决策。

## 产品北极星

Blueprint 是一个 **Agent 辅助的个人目标系统**。用户描述长期目标，Agent 帮助澄清约束、构建可审阅的路径图，并为适合学习的节点寻找 YouTube 视频。用户拥有最终蓝图，可以接受、替换或拒绝 Agent 的建议。

YouTube 是现阶段最重要的学习资源载体，不是产品边界。完整闭环是：

```text
长期目标
  → Agent 辅助构建路径
  → 用户审阅并拥有蓝图
  → 适合学习的节点绑定可替换的 YouTube 视频
  → 观看、理解与记录
  → 基于学习证据复盘
  → Agent 提议调整路径
```

Blueprint 近期不扩张为自动替用户执行现实世界任务的通用 Agent，也不以团队协作、排行榜或完整游戏经济为目标。当前先把个人目标规划、学习和复盘闭环做深。

## 当前基线：`2.0.0` 本地原型

### 已实现能力

- Chrome Manifest V3 扩展，包含 3D 蓝图主页、目标路径页、设置页和 YouTube 学习侧边栏。
- 科幻、赛博朋克、武侠和现代都市四种视觉主题。
- 以 Markdown 表达目标、里程碑和学习节点的分层蓝图。
- Agent 生成完整蓝图提案，用户预览确认后才持久化；并发写入有版本冲突保护。
- Windows Native Agent Host、Pi Agent Core 和 DeepSeek V4 Flash 组成的本地 Agent 边界。
- YouTube 原生字幕获取、视频概览、双语字幕、选文讲解和时间戳笔记。
- 自动化测试基线：2026-08-25 执行 `npm test`，63 项测试全部通过。

当前实现详情见[产品理念](product-vision.md)、[系统架构](architecture.md)和 [UI/UX 设计](ui-ux-design.md)。

### 主要缺口

- 蓝图、设置、会话和学习数据保存在 Chrome 本地存储中，没有账号、服务器数据或跨设备同步。
- Agent 依赖 Windows 本地 Host 和用户自己的 DeepSeek Key，安装与首次使用门槛较高。
- 3D 场景仍是基础几何体、硬编码灯光和粒子组成的演示级表达，主题与世界内容结合较弱。
- 蓝图规划提示只规定了基本工具顺序和提案规则，没有目标澄清方法、路径质量标准、视频检索工具或固定评测集。
- Agent 无浏览器和任意网络工具，不能验证它写入的 YouTube 视频是否真实、合适或具备可用字幕。
- 学习侧边栏仍保留旧 YouTube Digest 的部分视觉和交互心智，缺少目标上下文、学习进度和明确的返回路径。
- 扩展协调层、3D 页面和侧边栏由大型原生 JavaScript 文件承担，未来 Web 与扩展共享领域逻辑和组件的成本较高。

## 目标产品与系统边界

目标交付形态为 **Web 主站 + YouTube 扩展**：

```text
Web 主站 ─────────┐
                  ├─ 账号、云数据、目标与学习服务
YouTube 扩展 ─────┘           │
                              ├─ Agent / DeepSeek
                              ├─ YouTube Data API
                              └─ Supadata
```

- Web 主站承载账号、3D 蓝图、目标路径、规划师和复盘。
- 扩展专注于把目标节点连接到 YouTube，并提供伴随视频的学习工作台。
- PostgreSQL 的结构化实体成为事实来源，覆盖用户、蓝图、目标、通用路径节点、资源绑定、学习会话、证据事件和复盘。路径节点至少支持学习、实践、检查点和复盘；YouTube 是可选资源绑定，不是节点本体。
- Markdown 保留为 Agent 提案、用户审阅和导出格式，不再独自承担稳定 ID 与学习进度存储。
- Web 与扩展共享同一个账号身份和云端数据，但分别维护安全会话。扩展通过 Web 授权获得自己的会话；本地存储只用于缓存、短期恢复和待同步操作。
- Agent 只能生成提案。目标路径或复盘建议必须经过用户确认，才能写入正式蓝图。
- 新云端版本从空账号开始，不迁移或兼容现有 Chrome 本地数据；当前没有需要保留的真实用户数据。
- DeepSeek、YouTube Data API 和 Supadata 密钥全部保存在服务端。邀请测试阶段由平台承担额度，并设置账号级限制。
- Windows Native Agent Host 从目标方案中即时退役，不再作为新能力、迁移回退或兼容路径。相关源码只作为 `2.0.0` 历史基线，后续由新架构直接替换。

## 目标技术栈与适用组件

| 层次 | 选择 | 用途与约束 |
| --- | --- | --- |
| Web | Next.js App Router、React、TypeScript、Vercel | 承载登录、蓝图主页、目标路径、规划师和复盘；服务端能力与页面保持同一 TypeScript 技术栈。 |
| 数据与账号 | Supabase PostgreSQL、Auth、Row Level Security | 使用邮箱验证码与邀请码；所有用户数据表都通过行级权限隔离。参考 [Supabase Auth](https://supabase.com/docs/guides/auth) 和 [Row Level Security](https://supabase.com/docs/guides/database/postgres/row-level-security)。 |
| 浏览器扩展 | WXT、React、TypeScript、Manifest V3 | 将侧边栏、内容脚本、后台任务和构建入口组件化，并与 Web 共享领域类型。参考 [WXT](https://wxt.dev/)。 |
| 设计系统 | Tailwind CSS、自定义语义 Token、Radix UI/shadcn、Motion | 基础控件优先复用可访问组件；主题只改变视觉表达，不复制产品逻辑。 |
| 3D 表达 | Three.js、React Three Fiber、Drei、Blender、glTF | 构建以用户人物为中心的 3D 身份与目标状态面板；人物资产预留捏脸、换装和装饰插槽，当前只实现一个基础人物与主题。参考 [React Three Fiber](https://r3f.docs.pmnd.rs/)。 |
| Agent | Vercel AI SDK 7、DeepSeek 默认模型、模型适配层 | 将目标澄清、路径规划、资源匹配和复盘调整实现为分阶段、可评测、可版本化的服务端 Skills。参考 [AI SDK](https://ai-sdk.dev/docs/agents/building-agents)。 |
| 视频资源 | YouTube Data API、Supadata、独立可信度模块 | 按需检索候选视频，验证元信息和字幕；分别表达可用性、内容匹配、原始平台信号和编辑推荐，不依赖模型记忆或未经合规确认的综合分。参考 [YouTube Data API](https://developers.google.com/youtube/v3/docs/search/list)。 |
| Agent 质量 | Langfuse、固定评测集、人工评分规则 | 比较提示、模型和工具策略；评测与观测数据必须脱敏。参考 [Langfuse Evaluations](https://langfuse.com/docs/evaluation/core-concepts)。 |
| 质量与观测 | Vitest、Playwright、无障碍检查、Sentry、最小产品事件 | 覆盖领域逻辑、Web、扩展、端到端流程和线上故障；从首条云端流程开始记录脱敏行为事件，但暂不预设邀请测试的数值淘汰门槛。 |

## M0：本地原型基线

**状态：已实现**

这一阶段证明了目标蓝图、用户确认的 Agent 提案和 YouTube 学习侧边栏可以连成一条产品路径。由于当前不存在需要保留的真实用户数据，Windows Native Agent Host 和本地存储方案从后续路线中立即退出，不建立兼容或迁移层，也不继续增加新能力。

完成证据：

- 当前发布版本为 `2.0.0`。
- [`package.json`](../package.json)、[`manifest.json`](../manifest.json) 和现有产品文档共同描述本地双组件形态。
- 2026-08-25 执行 `npm test`，63 项测试通过。

## M1：通用领域与云端纵向切片

**状态：下一步**

### 用户结果

开发者使用免费服务层完成个人自测：登录 Web、建立一份通用目标路径，并在扩展中以同一账号读取对应目标和节点。该阶段先证明身份、数据与双端连续性，不要求同时交付完整 Agent、3D 美术和学习能力。

### 顶层交付

- 建立 Next.js Web、WXT 扩展和共享 TypeScript 领域契约的目标目录边界，按纵向切片迁移而不是全量重写。
- 将领域模型从“学习节点”提升为通用路径节点，至少支持学习、实践、检查点和复盘；资源绑定独立存在。
- 使用 Supabase 建立稳定 ID、版本化蓝图、用户确认的提案语义和 Row Level Security。
- 建立邀请制邮箱验证码登录；扩展通过 Web 授权获得独立会话，两端使用同一个用户身份和数据。
- 先以手工或测试蓝图打通 Web 创建、扩展读取、节点跳转和一条记录回写。
- 从第一条纵向流程开始记录脱敏行为事件、调用量、同步失败和恢复结果。
- Windows Native Agent Host 不进入新目录和运行链路，不实现历史数据导入。

### 完成门槛

- 一个自测账号可以在 Web 完成登录、退出和会话恢复，并授权扩展访问同一账号。
- 用户可以创建、查看和修改包含不同类型节点的蓝图，Web 与扩展看到一致结果。
- 跨用户读取和写入被数据库权限拒绝，客户端构建产物中不存在服务端密钥。
- 云端版本的蓝图修改继续保持“提案—确认—版本条件写入”，不会因迁移丢失用户控制。
- 同步失败不会丢失当前输入或已经保存的记录；最小行为事件可在不记录正文的情况下查询。
- 产品文档、隐私说明和安全边界已区分历史本地版本与目标云端版本。

## M2：通用 Agent Skills 管线

**状态：计划，依赖 M1**

### 用户结果

用户可以从方向明确但路径模糊的目标开始，通过对话补齐必要信息，确认目标定义，再获得结合起点、时间、期限和成功标准的路径提案。

### 顶层交付

- 将目标澄清、路径规划、资源匹配和复盘调整定义为四个可版本化的服务端 Skills，由系统按状态自动编排。
- 四个 Skill 的公开规范、研究方法、可借鉴实现与许可证边界见 [Agent Skill 研究](agent-skill-research.md)。
- 目标澄清 Skill 收集现状、每周投入、期限、约束和成功标准；用户确认目标定义后才能进入路径规划。
- 路径规划 Skill 生成通用类型节点和依赖关系，不在业务代码中为单一技能领域写死规则。
- 所有 Skill 只生成结构化草案或提案，正式蓝图仍由用户确认后以版本条件写入。
- 建立覆盖编程、语言、健身、创作等代表性场景的固定评测案例、结构检查、人工评分和失败库。评测案例用于证明通用性，不限制产品接收的目标类型。
- 生产目标正文默认不进入普通产品分析；评测优先使用合成或明确授权的脱敏案例。

### 完成门槛

- 信息不足时 Agent 会继续澄清而不是伪装完成；信息充分时用户可以确认一张目标定义卡。
- 路径包含与目标相符的学习、实践、检查点和复盘节点，且可以在没有视频的情况下成立。
- 提案差异、依据和不确定性对用户可见；拒绝提案不会改变正式蓝图。
- 每次修改 Skill、模型或工具策略前后都运行同一跨领域评测，并能指出提升和退化场景。

## M3：3D 身份与目标状态面板

**状态：计划，依赖 M1**

### 用户结果

用户打开首页时看到的是代表自己的虚拟人物、周围的目标状态和明确的下一步行动，从而产生“这是我的蓝图”的归属感，而不是面对普通任务列表或可漫游游戏世界。

### 顶层交付

- 用一个正式基础人物、一个原创赛博蓝图主题、目标 HUD、当前重点和轻量待机动作构成 3D 状态面板。
- 目标、状态和操作由 DOM 承载；3D 人物负责身份表达，不承担复杂表单或必要文本。
- 首页最多环绕展示 5 个活跃目标，其他目标通过“全部目标”访问；目标详情仍进入独立路径页。
- 美术和领域结构预留基础形态、发型、服装、手持物、挂件、奖牌、姿态和环境底座等扩展槽位，当前不实现捏脸或完整换装编辑器。
- 为低性能、窄屏、减少动态效果和 WebGL 不可用状态提供等价的 2D 或预渲染形象。
- UI 设计、核心流程和线框图以[目标 UI/UX 规划](target-ui-ux-plan.md)为准。

### 完成门槛

- 用户无需说明即可指出当前重点目标、下一步行动和最近取得的证据。
- 人物、目标 HUD 和交互层级在空目标、1–5 个活跃目标、长标题和窗口缩放时保持可读。
- 关闭 3D 或减少动态效果后，登录、目标选择、规划和路径访问仍完整可用。
- 正式人物资产接入后再记录首屏、帧率和体积基线，并据此确定发布性能预算。

## M4：可信视频与 YouTube 学习伴侣

**状态：计划，依赖 M1 与 M2；不依赖 M3 的完整美术资产**

### 用户结果

学习类节点可以获得真实、可解释和可替换的视频候选；用户从 Web 进入 YouTube 后，始终知道为什么学习、要留下什么证据以及如何返回路径。

### 顶层交付

- 视频只在学习类节点需要资源时按需检索，减少 YouTube 搜索配额消耗；Agent 只能选择服务端返回的真实视频 ID。
- 可信度模块分别处理硬性可用性、内容匹配、YouTube 原始指标和独立编辑推荐；不使用已废弃的收藏数，也不在合规审计前展示 KOC 综合数字分。
- 每个节点提供一个经过验证的默认推荐和两个备选，显示语言、时长、字幕、发布时间、来源和适配理由，允许替换或移除。
- 将 Side Panel 改造为与目标、节点和视频绑定的学习会话，重组为“学习、理解、记录”三个任务视图。
- 增加固定目标上下文、完成依据、返回路径和继续学习入口，不复制新的播放器。
- 优化首次加载、长字幕、无字幕、请求失败、Agent 不可用和笔记保存失败的恢复路径。
- Web 与扩展共享设计 Token、术语和状态表达；不强求共享所有 React 组件。

### 完成门槛

- 所有推荐视频来自真实检索并通过可用性检查；字幕验证只针对排名靠前的候选执行。
- 用户能理解默认推荐的理由、查看两个备选，并主动替换、移除或暂不使用视频。
- 用户能从目标节点进入正确视频，完成一次理解或记录行为，并返回原目标路径。
- 长字幕、双语、选择讲解和笔记操作在键盘、触控和窄侧边栏中均可用。
- 错误不会丢失准确原文、用户笔记或已经完成的学习操作。
- 学习工作台不再出现与 Blueprint 主产品冲突的旧品牌、入口说明或视觉层级。

## M5：学习证据、复盘与身份积累

**状态：计划，依赖 M1 与 M4**

### 用户结果

用户可以跨设备继续学习，用理解、实践和检查点证据判断真实进展，完成一次复盘；用户确认的成果同时改变路径状态和人物的长期身份表达。

### 顶层交付

- 同步播放位置、观看比例、笔记和讲解等活动，并与理解、实践、检查点和复盘证据分层展示。
- 由用户根据节点完成依据明确确认“未开始、学习中、已完成或待复习”，系统不根据观看时长自动声称掌握。
- 提供继续学习、阶段回顾、复盘摘要和复盘调整 Skill。
- Agent 只基于用户可见的学习证据提出路径调整，不根据观看时长自动声称用户已经掌握。
- 所有复盘修改继续经过预览和用户确认。
- 首版游戏化只包含里程碑奖牌、人物挂件和用户主动生成的分享卡片；奖励主要绑定实践、检查点和有效复盘。

### 完成门槛

- 用户在另一设备登录后能恢复最近学习位置和相关笔记。
- 用户可以完成一次阶段复盘，并看懂每条调整建议使用了哪些学习证据。
- 拒绝复盘建议不会改变现有蓝图或完成状态。
- 完成实践、检查点或复盘后，用户可以获得与证据来源一致的奖牌或人物装饰；仅观看或发布空状态不会获得核心奖励。
- 用户可以导出或删除自己的进度、笔记和复盘数据。

## M6：邀请测试与公开化准备

**状态：计划，依赖 M2 至 M5 形成完整纵向闭环**

### 用户结果

产品先从个人免费层自测切换到小范围邀请测试，观察目标澄清、路径确认、学习证据、复盘、成本与连接表现；形成数据基线后再确定数值门槛和是否扩大开放。

### 顶层交付

- 第一个外部用户进入前配置可用 SMTP、服务稳定性、隐私说明、全局预算、账号额度、并发限制和异常熔断。
- 邀请测试初始总预算上限为每月人民币 800 元；个人自测阶段优先使用 Supabase、Vercel 和 Supadata 免费层。
- 建立目标澄清、路径提案、资源选择、学习证据、复盘、扩展授权、同步失败和恢复事件；事件不记录目标正文、字幕、笔记或作品内容。
- 根据个人自测和首批使用数据建立基线，再决定阶段淘汰或扩大门槛，不预先用缺少证据的百分比承诺成功。
- 开放自助注册前补齐更完整的额度管理、防滥用、隐私控制、数据导出和运营监控。
- 根据邀请测试的连接数据决定是否建设面向中国大陆直连的独立部署方案。
- 验证具有清晰版权、元信息和内容访问边界的非 YouTube 学习资源适配器。
- 保持个人目标系统定位，不提前进入团队协作、通用任务执行或社交排行榜。

### 完成门槛

- 规划、资源、学习和复盘闭环已经产生可查询的真实行为与用户反馈基线，并据此记录下一阶段数值门槛。
- 公开注册的成本、服务额度、隐私说明和滥用处理方式可持续。
- 新资源适配器遵守与 YouTube 节点相同的来源透明、可替换和用户确认原则。

## 跨阶段质量原则

- **用户拥有数据与决策**：Agent 提案不等于已修改，任何路径变更都必须清楚展示并由用户确认。
- **事实来源清晰**：当前版本以本地 Markdown 为事实来源；云端版本上线后以结构化 PostgreSQL 数据为事实来源，Markdown 是提案与导出格式。
- **失败可见且可恢复**：登录、同步、Agent、视频和字幕失败都说明原因与下一步，不伪装成功。
- **隐私最小化**：产品分析只记录必要行为事件，不记录目标正文、字幕、选文、笔记或模型密钥。
- **可访问性不是降级功能**：3D、主题和动效不能阻断键盘、触控、窄屏、减少动态效果或非 WebGL 用户。
- **质量先测量再优化**：Agent、3D 性能和学习体验都先建立基线，再用相同条件比较迭代结果。

## 关键风险

| 风险 | 当前处理方式 | 重新决策触发条件 |
| --- | --- | --- |
| 中国大陆访问国际服务不稳定 | 邀请测试仅面向可稳定访问 YouTube、Vercel 和 Supabase 的用户，不承诺境内无代理直连 | 连接失败成为主要流失原因，或准备公开注册 |
| 平台承担模型、检索和字幕费用 | 个人自测先使用免费层；外部邀请前设置每月人民币 800 元全局预算、账号额度、超时、并发限制和异常熔断 | 预算阻断正常自测，或单用户成本随使用持续上升 |
| Web 与扩展产生两套产品逻辑 | 共享 TypeScript 领域模型、身份和设计 Token，扩展只保留 YouTube 学习场景；Web 授权扩展但两端分别维护会话 | 同一功能在两端出现不一致行为，或授权失败成为主要流失点 |
| 3D 美术投入拖慢核心闭环 | M3 只做一个人物、一个原创主题和 DOM HUD，预留但不实现捏脸与完整换装；保持 2D 降级 | 3D 阻碍目标阅读、下一步行动或低端设备使用 |
| 通用 Agent 管线在具体领域失效 | 业务代码不硬编码领域，但用跨领域固定案例持续评测目标澄清、节点结构和行动可行性 | 评测显示某类目标持续产生不可执行路径 |
| Agent 推荐错误或视频失效 | 按需真实检索，分离可用性、内容匹配、原始平台指标和编辑推荐，提供一个默认与两个备选 | 资源有效性或用户替换率显示推荐不可信 |
| YouTube 配额与派生指标政策限制可信度模块 | 只为选中学习节点按需搜索，不使用已废弃收藏数；合规审计前不展示 KOC 综合分 | 搜索配额不足以支持自测或准备引入外部评分合成 |
| 游戏化奖励诱导刷状态 | 核心奖励绑定实践、检查点和有效复盘，不绑定单纯观看、登录或空状态数量 | 行为事件增加但证据质量下降 |
| 目标和学习数据包含敏感信息 | 最小化日志和分析内容，错误追踪、评测与产品分析默认脱敏 | 引入新的第三方数据处理方或公开注册 |

## 文档维护规则

在以下任一事件发生时更新本文档：

- 阶段开始、完成、暂缓或顺序改变。
- 一个完成门槛获得可验证证据，或发现原门槛无法代表用户结果。
- 产品载体、数据事实来源、第三方服务、Agent 边界或隐私策略改变。
- 新风险影响当前阶段，或已有风险触发重新决策条件。

每次更新应同时完成：

1. 修改“最后更新”“当前阶段”和“下一阶段”。
2. 更新阶段状态与完成证据，优先链接到发布版本、测试结果、用户研究或合并记录。
3. 在“关键决策记录”中补充方向变化及原因，不静默覆盖旧决定。
4. 检查[产品理念](product-vision.md)、[系统架构](architecture.md)和 [UI/UX 设计](ui-ux-design.md)是否仍准确描述当前已实现版本，并检查[目标 UI/UX 规划](target-ui-ux-plan.md)是否与未来路线一致。
5. 不在路线文档中展开接口协议、数据库字段、逐文件任务或临时实现细节。

## 已确认假设

- 首批用户为工作 0–3 年、有职业技能提升或转岗目标、能稳定访问 YouTube、Vercel 和 Supabase 的中文用户；当前路线不承诺中国大陆境内无代理直连。
- 个人自测使用 Supabase、Vercel 和 Supadata 免费层；外部邀请阶段由平台承担 Agent、视频检索和字幕费用，每月初始预算上限为人民币 800 元。
- 阶段按完成门槛推进；在团队规模与投入时间未确定前不写死日历工期。
- 当前没有需要保留的真实用户数据，不建设旧版数据迁移或兼容能力；Windows Native Agent Host 不进入新架构。
