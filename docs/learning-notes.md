# 私人时间戳笔记

更新：2026-09-10；固定点 `1db1c1d`。这是 P4/P8 的云端领域与读写入口增量，已在本地数据库和生产形态服务中验证，尚未部署，也尚未接入笔记表单或播放器。

## 数据与产品边界

笔记记录用户在某个正式节点、某条 YouTube 资源下的原文与可选位置。它独立于成果证据、自评状态和学习会话：保存笔记不改变蓝图版本，不制造观看、完成或掌握记录。位置是显式提供的秒数；零与未提供不同，不代表系统验证过观看时长或视频长度。

正文原样保存空格和换行，允许 1–8000 个 Unicode 字符，拒绝纯空白、NUL 和无效代理字符。节点名称、层级、版本和视频来源由服务端从当前所属资源取得，客户端不能伪造。历史独立保存当时上下文；后续改名、归档、替换或移除绑定，不会把旧笔记移到新视频。

同一提交标识的完全相同请求返回原回执；即使来源后来改变，也不会重复创建。更改正文、位置或来源后沿用旧标识则拒绝。新笔记必须基于当前版本和未归档的所属绑定。写入与正式路径确认使用一致的蓝图锁顺序，避免并发确认时保存混合来源。

读取一次返回同一数据库快照下的正式蓝图及最近 50 条笔记，按保存时间和 ID 倒序；旧笔记没有被删除，但这不是完整导出或分页接口。本批只支持新增与读取，不宣称已实现编辑、删除、自动播放进度、字幕讲解或跨设备继续播放。

## 身份与共享入口

- [共享领域模型](../packages/domain/src/learning-notes.ts)表达笔记及严格提交边界。
- [服务端用例](../apps/web/src/lib/learning-notes.ts)校验账号、历史一致性与精确回执，未知错误仅返回不可用分类。
- [Web Actions](../apps/web/src/app/learning-note-actions.ts)核实当前 Cookie 身份与页面预期账号；[扩展 HTTP](../apps/web/src/app/api/v1/learning-notes/route.ts)写入只接受已核实的配置扩展身份，Cookie-only 写入被拒绝。两者读取同一份云数据，不使用管理员密钥。
- [增量迁移](../supabase/migrations/20260910142009_learning_notes.sql)显式设置权限和账号 RLS，拒绝匿名用户、未知 OAuth 客户端、另一账号及直接表写入。私有写入函数再次核验身份与来源；公开包装函数和快照读取保持调用者权限。

HTTP 正文使用共用 64 KiB 实际字节限制与五秒读取期限，私密结果禁止缓存。真实生产模式测试先复现 Next 代理等待上传结束，随后仅将此精确入口交给自身认证与读取器；相邻路由仍走原代理。五秒不是完整认证／网络请求的总期限。
