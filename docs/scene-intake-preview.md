# 本地 3D 资产试装

2026-09-09，P2 内部试装工具，不是 P5 正式蓝图主页。

## 使用与隔离

运行本地 Web 开发服务，进入 `/design` →「打开真实人物试装」，或直接访问 `/design/assets`。选择已核验来源、资源全部内嵌的 glTF 2.0 JSON 文件，最大 10 MB。实际人物文件见 [资产台账](asset-intake.md)，放在 Git 忽略的外置盘目录中。

文件经浏览器 File API 本地读取，验证后通过 [Three.js GLTFLoader.parseAsync](https://threejs.org/docs/pages/GLTFLoader.html) 解析；拒绝外部 URI，加载器还限制实际资源请求。没有上传端点、数据库写入、模型服务调用或自动安装解码器。仅用于可信来源候选，不将文件大小上限视为任意恶意 3D 文件的完整资源沙箱。

生产构建中 `/design` 与 `/design/assets` 均返回 404。人物不放入 public，不将许可证对应关系尚有疑问的文件随源码分发。Web-only 运行时使用 Three.js 0.186.0、React Three Fiber 9.7.0、Drei 10.7.8；开发类型为 @types/three 0.185.4，实际锁文件为准。共享 UI 与扩展不引用这些运行时。

## 实际提供的检查

- 画布、旋转／缩放、基础主光／轮廓光、阴影与中性试装台；自动归一化人物高度，不是正式世界构图。
- 默认静止；可播放 `Idle_Neutral`。页面隐藏或系统减少动态效果时停止持续动画，静止时按需重绘。
- `Sword` 是这名候选可识别的部件名；开关不承诺可自动理解任意人物的武器、服饰或装备。
- 文件解析错误保留当前模型；清除／替换时释放已完成加载的模型资源，迟到加载结果不覆盖新状态。
- WebGL 不可用或场景渲染错误有文字回退，文字状态与文件入口不依赖 Canvas。非 WebGL 真设备和主动 context-loss 恢复尚未验收。

## 本轮证据与限制

ego-browser 实际加载 Character.gltf：画布内人物可见、武器可隐藏、22 个动作被解析，待机开关已操作；截图存于本地 `.goal-loop/evidence/2026-09-09-character-intake.png`，不是发行方效果图。测试外链 `https://example.com/do-not-fetch.bin` 被校验拒绝，原场景保留，浏览器 Resource Timing 未出现该外链请求；清除后画布移除，再选原模型成功。没有请求外部资产。

校验器用 red→green 验证外部 URI、版本、大小上限和允许的内嵌输入。浏览器没有框架错误覆盖层；R3F 仍使用 Three.js 已弃用的 Clock，存在兼容性警告，需随框架升级检查。本工具显式使用 PCFShadowMap，避免默认旧阴影枚举的警告。

本次未测得正式 FPS、8 MB 网络预算或 3 秒 DOM 门槛；减少动态效果已模拟，但未把这种检查当作跨设备完整性能验收。此候选人物尚不足以作为正式用户化身，东方人物与全场景仍待制作。工具不替代双主题美术评审。
