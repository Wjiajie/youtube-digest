- 每页最多 20 段，完整输入数据提示不超过 64 KiB；超限明确拒绝，不静默截断原文。当前目标语言为简体中文，符合首批中文用户定位；其他目标语言尚未开放。
- 只接受与账号、绑定、视频、固定来源及页码一致的字幕。无材料、空页、未固定来源或来源读取耗时已超过期限时，不调用模型。
- 一次模型请求，不使用工具或自动重试。只把语言和段落正文交给模型，不附带账号 ID、目标正文、节点名称或视频标题。
- 模型只能返回逐段译文及段落序号。缺段、多段、重复、错序、伪造序号、空白、额外字段或截断响应均拒绝整页，不拿部分结果覆盖原文。
- 原始文字、序号和时间由程序保留；来源摘要与 Skill 摘要用于后续运行核对。同一来源的再次读取不因观测时间变化产生新证据摘要。
- 来源期限沿用原始材料的数据库期限，扣除完整读取耗时；在请求前、执行期间和接受结果前检查。用户取消、来源过期与模型执行超时分别表达，迟到响应不能复活结果。未知消耗仍保留不确定标记，不承诺取消会阻止提供方计费。
- 返回用量和来源元信息，普通遥测与模型警告不包含字幕正文。译文是待以纯文本展示的数据，不是可信 HTML、可执行指令或经过语义验证的事实。
