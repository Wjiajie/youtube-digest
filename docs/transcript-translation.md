# 双语字幕：服务端翻译引擎

2026-09-11 · P8 进行中 · 固定点 `b7fa2be`。已实现来源绑定的内部翻译引擎和版本化 Skill，**尚未开放 Web／扩展翻译入口，也未完成持久运行、额度和双端展示**。本文件不代表用户已可使用完整双语字幕。

## 目标体验与本批能力

目标是在当前节点的视频字幕中并列阅读原文和简体中文译文，保留段落与时间定位。翻译辅助理解，不代替原文、不证明内容正确，也不写入完成度、掌握度或蓝图修订。后续用户明确发起生成，刷新或跨设备后应能恢复已持久化结果，不自动再次消费。

[翻译引擎](../apps/web/src/lib/agent/transcript-translator.ts)复用现有 AI SDK 结构化生成策略，新增固定的[翻译 Skill](../apps/web/src/lib/agent/skills/translate-transcript/v1/SKILL.md)。调用方提供预先分配的生成 ID、经过身份核验的固定来源页和当前进程的读取起始时间；身份和数据库授权仍由调用方负责，不能把此函数当作公开的授权接口。

- 每页最多 20 段，完整输入数据提示不超过 64 KiB；超限明确拒绝，不静默截断原文。当前目标语言为简体中文，符合首批中文用户定位；其他目标语言尚未开放。
- 只接受与账号、绑定、视频、固定来源及页码一致的字幕。无材料、空页、未固定来源或来源读取耗时已超过期限时，不调用模型。
- 一次模型请求，不使用工具或自动重试。只把语言和段落正文交给模型，不附带账号 ID、目标正文、节点名称或视频标题。
- 模型只能返回逐段译文及段落序号。缺段、多段、重复、错序、伪造序号、空白、额外字段或截断响应均拒绝整页，不拿部分结果覆盖原文。
- 原始文字、序号和时间由程序保留；来源摘要与 Skill 摘要用于后续运行核对。同一来源的再次读取不因观测时间变化产生新证据摘要。
- 来源期限沿用原始材料的数据库期限，扣除完整读取耗时；在请求前、执行期间和接受结果前检查。用户取消、来源过期与模型执行超时分别表达，迟到响应不能复活结果。未知消耗仍保留不确定标记，不承诺取消会阻止提供方计费。
- 返回用量和来源元信息，普通遥测与模型警告不包含字幕正文。译文是待以纯文本展示的数据，不是可信 HTML、可执行指令或经过语义验证的事实。

## 验证边界

先红后绿覆盖原文对应、异常输出、固定来源、大小限制、Skill 修订不匹配、读取耗时到期、在途到期及结果／定时器竞争。另覆盖调用方修改原输入、空材料、取消、独立模型超时、错误脱敏和不自动重试。

[实际 SDK 本地 HTTP 旅程](../apps/web/src/lib/agent/transcript-translator.integration.test.ts)经现有 DeepSeek SDK 发送到回环夹具，验证结构化请求、单次调用、原文对应及用量回执；没有调用真实提供方。夹具固定译文只能证明接线和结构，**不能证明真实翻译质量、忠实度或模型抵御提示注入的能力**。真实质量评测仍需单独验证否定、数值、术语、残句、混合语言和语境歧义。

27 项新增翻译测试通过。完整 `check:m1` 通过 1002 项应用测试、79 项后台测试、四工作区类型检查、6 项压缩回归、4 项维护 CLI 检查、进程内迁移契约、向导、Next／WXT 构建及扩展安全检查。无界面或数据库行为变更，本批未重跑浏览器、真实 Auth 或共享数据库全套检查；不复用上一批这些结果作为本批独立执行证据。

本批不改数据库、Worker 授权、公共路由、Next 文件打包配置或两端界面；没有生成正文进入数据库，也没有新增消费路径。引擎只有测试调用方，接入用户入口前必须完成下述持久链。无真实内容服务、费用、部署或 push；本地 22 项／托管最后核实 7 项迁移不变。

## 下一批：持久运行与双端接入

1. 建立独立的私有翻译运行，按 ID 恢复，生成前分配身份并预留额度。数据库读取固定字幕，拒绝客户端自带正文；固定模型配置、Skill 正文／摘要、来源和不可延长的期限。重放原运行不得再次生成或扣次。
2. 接通领取、完成、取消及不确定结果恢复。来源仍需符合当前绑定与账号，历史有效字幕不能被误限定为最新蓝图版本。模型／用量／成本元数据由持久运行记录承载，不在引擎里另建一套账户或计费系统。
3. 显式接入原材料整链清除与期限维护：原始输入、译文和引用同时受限；保留无正文终态回执，清除后迟到完成不能复活。维护和备份删除的既有缺口继续保留，不能只增加一张表就宣称合规。
4. 审查扩展的窄生成入口。现有通用执行 Worker 拒绝 OAuth 客户端，不能为翻译而直接放宽全部 Worker 或暴露原始资源表。分别验证 Web 身份和精确扩展客户端权限。
5. 最后接入共享双主题并列阅读、明确生成与失败恢复、键盘／触控操作；补做真实账号、实际扩展、长字幕及到期隐藏旅程。公共路由引入 Skill 时，再明确配置其生产文件打包。

现有资源运行不能直接增加一种类型来复用：它限定三种操作、来源唯一和匹配专用 Skill，且有当前版本和单次消费规则，与有效历史字幕及逐页翻译不同。复用执行纪律，而不是放宽旧运行的业务约束。

内容获取、模型处理、再展示权限和真实费用继续受[资源门槛](resource-retention-research.md)及[来源期限](resource-evidence-expiry.md)约束。全部工作仍属于[执行路线](execution-roadmap.md)的 P8，不代替 P2 正式美术或 P9 联合验收。
