## 当前增量：可恢复的私有运行

[数据库运行](../supabase/migrations/20260910235701_translation_runs.sql)独立于已有检索／字幕／匹配运行，不放宽旧类型或 Worker 权限。Web 调用方可明确创建、读取和取消；领取、完成仅限服务端。所有翻译表位于私有 schema 并启用 RLS，连服务角色也没有直接表读写权限。当前所有 OAuth 客户端和匿名身份均拒绝，扩展接入需要后续窄范围授权。

- 创建只接受生成 ID、绑定、视频、固定来源、页码和目标语言，数据库自行读取原文。每账号至多一条活动运行，未配置额度时拒绝创建。同 ID 同参数仅恢复，改变参数拒绝；读取不调用模型或重复预留额度。
- 原文页与原始材料期限不可替换或延长。有效历史字幕仍可使用；学习、实践、检查点和复盘节点均可拥有有效的视频绑定。
- 领取仅成功一次，固定模型 ID 与 Skill 正文／版本／摘要。数据库观测时间独立于应用时钟；排队与执行各最多 120 秒且不超过来源期限，引擎仍有更短的 60 秒上限。
- 完成只保存逐段序号／译文和用量，原文由冻结页保留。同结果重放可恢复，改变结果或错误执行凭证拒绝；取消、超时或清除后的迟到完成不能重新开放内容。
- 未领取时取消、超时或清除只返还一次额度；已领取按“可能已执行”处理，不因取消／失败自动返还。令牌用量保留未知值，不冒充精确人民币账单。
- 原资源整链清除同步清空关联翻译的原文页、Skill、模型和结果，保留无正文终态回执。既有到期维护因此覆盖翻译，读取／领取／完成再次检查期限与当前绑定。正式蓝图、历史修订和用户笔记不属于此次清除对象。
- 单次访问只核查请求运行和账号至多一条活动运行，不逐条读取整个历史字幕库；延续蓝图优先加锁顺序。

[调用方适配器](../apps/web/src/lib/agent/translation-run-access.ts)和[内部执行适配器](../apps/web/src/lib/agent/translation-run-worker.ts)核对账号、生成 ID、固定页、状态、摘要和观测回执，不回传数据库错误正文。它们不是已部署的公开执行服务；正式入口仍须核验登录会话、连接生命周期取消和可信执行配置。

## 前批引擎：目标体验与能力

目标是在当前节点的视频字幕中并列阅读原文和简体中文译文，保留段落与时间定位。翻译辅助理解，不代替原文、不证明内容正确，也不写入完成度、掌握度或蓝图修订。后续用户明确发起生成，刷新或跨设备后应能恢复已持久化结果，不自动再次消费。

[翻译引擎](../apps/web/src/lib/agent/transcript-translator.ts)复用现有 AI SDK 结构化生成策略，新增固定的[翻译 Skill](../apps/web/src/lib/agent/skills/translate-transcript/v1/SKILL.md)。调用方提供预先分配的生成 ID、经过身份核验的固定来源页和当前进程的读取起始时间；身份和数据库授权仍由调用方负责，不能把此函数当作公开的授权接口。

- 每页最多 20 段，完整输入数据提示不超过 64 KiB；超限明确拒绝，不静默截断原文。当前目标语言为简体中文，符合首批中文用户定位；其他目标语言尚未开放。
- 只接受与账号、绑定、视频、固定来源及页码一致的字幕。无材料、空页、未固定来源或来源读取耗时已超过期限时，不调用模型。
- 一次模型请求，不使用工具或自动重试。只把语言和段落正文交给模型，不附带账号 ID、目标正文、节点名称或视频标题。
- 模型只能返回逐段译文及段落序号。缺段、多段、重复、错序、伪造序号、空白、额外字段或截断响应均拒绝整页，不拿部分结果覆盖原文。
- 原始文字、序号和时间由程序保留；来源摘要与 Skill 摘要用于后续运行核对。同一来源的再次读取不因观测时间变化产生新证据摘要。
- 来源期限沿用原始材料的数据库期限，扣除完整读取耗时；在请求前、执行期间和接受结果前检查。用户取消、来源过期与模型执行超时分别表达，迟到响应不能复活结果。未知消耗仍保留不确定标记，不承诺取消会阻止提供方计费。
- 返回用量和来源元信息，普通遥测与模型警告不包含字幕正文。译文是待以纯文本展示的数据，不是可信 HTML、可执行指令或经过语义验证的事实。
