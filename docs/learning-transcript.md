# 双端原始字幕阅读

更新：2026-09-11；固定点 `5b6830c`。P8 本地实现增量，不代表真实字幕服务已启用或完整学习工作台完成。

## 用户体验

Web 正式路径中的视频提供“阅读原始字幕”入口；扩展新增有实际功能的“理解”任务区，始终依附当前视频的明确节点绑定。两端共用阅读组件，保留赛博控制台与东方纸页的语义主题。说明收进可展开的来源区，让正文优先出现在窄屏中。

- 用户主动读取已获取的原文，每页最多 20 段；不自动获取、调用模型或扣除次数。
- 分页固定同一份来源，避免翻页时偷偷更换材料；“查找最新字幕”才重新选择来源。
- 原文、原始语言与顺序保留。来源可能对应历史路径版本，不是当前推荐或掌握证明。
- 时间链接在新标签页打开原 YouTube 视频；不直接控制播放器、自动播放或保存学习进度。
- 尚未获取、处理中、不可用、已到期和已清除分别说明；无字幕不妨碍已有笔记、成果和自评。
- 切换任务只隐藏同一账号内的工作区，笔记及位置草稿不会因此被卸载。主题改变不更改数据含义。

## 模块与数据边界

[共享领域校验](../packages/domain/src/learning-transcript.ts)定义严格的来源、绑定和分页结果；[共享阅读器](../packages/ui/src/learning-transcript.tsx)处理呈现、键盘、有效期限和迟到响应。[Web 页面](../apps/web/src/app/learn/[bindingId]/page.tsx)与[扩展面板](../apps/extension/entrypoints/sidepanel/TranscriptPanel.tsx)只适配各自的身份和当前学习上下文。

新增的[窄读取投影](../supabase/migrations/20260910211356_learning_transcript.sql)允许已核验 Web 用户与精确配置的扩展 OAuth 客户端读取本人当前绑定的视频片段。不开放原始资源运行表、整条模型输入或其他候选；原有资源执行、清理与原始记录读取权限不变。未知 OAuth、匿名身份、跨用户、错误视频及失效绑定被拒绝。读取与绑定变更／证据清除遵循已有蓝图锁顺序。

最新匹配来源不可读时不偷偷回退到旧正文。显式来源分页不会换源；历史来源只有仍属于本人当前节点和视频、处于可读终态且具有有效保留期限时才能使用。没有有效期限的旧材料不输出正文。读取不续期、不清理、不创建会话、不改变正式路径和进度。

HTTP 禁止缓存，首次服务器渲染不包含字幕；客户端不将正文写入浏览器存储或分析事件。界面使用数据库剩余期限扣除单调请求耗时，避免客户端与数据库时钟偏差扩大显示时间。到期、读取失败、账号／绑定变化，以及返回窗口或恢复可见时隐藏旧正文并丢弃迟到响应，要求用户明确重读。此机制不撤回已经交付给客户端或被用户复制的文字，也不等于 DRM 或即时跨设备撤回；其他设备清除后，当前已显示页最迟在本页期限到达或下次核对时隐藏。

## 验证

先红后绿覆盖真实 SQL 投影、共享响应校验、用户操作和扩展 HTTP 边界。新增 54 项数据库检查覆盖权限、当前绑定、历史版本、分页、期限、清除、长文本及 UTF-16 长度；完整 22 文件共 1143 项通过。已有数据升级逐行保留原数据及旧函数定义／权限，本地迁移历史为 22 项，结构无未提交差异。

74 项真实本地 Auth 集成通过，新增旅程使用真实账号和数据库完成“无材料 → 可读原文 → 分页 → 外人拒绝 → 主动清除”，不调用真实提供方。共享 React 测试覆盖延迟消耗期限、失效后的迟到响应、账号变化、安全文本和固定来源分页。

浏览器证据分开解释：Web 使用本地真实账号、生产构建和真实数据库；MV3 使用实际 WXT 产物、Chrome 消息与隔离 HTTP／YouTube 夹具。它们验证产品接线与生命周期，不证明真实提供方质量或真实 OAuth 登录链路。最终三条真实账号学习页旅程、50 项默认生产 Web 回归及六条 MV3 旅程通过；旧两页签键盘断言先失败，更新为遍历学习／理解／记录三页签后全部通过，保留原有草稿和强制颜色检查。

完整 `check:m1` 通过：960 项应用测试、79 项 Edge 测试、四工作区类型检查、六项压缩测试、四项维护 CLI 测试、升级契约、向导、Next／WXT 构建和扩展安全检查。扩展产物 662.05 kB，权限未变；新增真实账号／浏览器夹具另做严格类型检查。主线程检查双主题 Web 宽窄屏与 MV3 320px 截图，正文、长标题、按钮和页签无横向溢出；此检查不代表全部读屏或真实设备门槛通过。
