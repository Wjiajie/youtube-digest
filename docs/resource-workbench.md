# 双主题节点资源工作台

更新：2026-09-10；固定点 `decaefe`。本批把已有资源执行链接到正式路径的学习节点，提供检索条件、运行历史、候选阅读、字幕继续、匹配依据与明确恢复。默认关闭真实消费；采用／替换资源仍未实现，不自动修改正式路径。

## 用户旅程

从正式路径的学习节点进入“查找与审阅学习资源”，先核对节点要求、完成依据和预计投入。观看地区必须由用户明确填写；字幕语言、允许语言回退、视频时长、最早发布日期以及可选起点／约束均可调整。未绑定视频的节点仍有效，实践、检查点与复盘不强制出现检索按钮。

一次明确点击只发起一次操作。界面立即提供本次记录的新标签页入口，不等网络返回才提供恢复；结果未知时保留该入口、阻止重复发起，不自动重试或轮询。检索、读取待处理字幕和内容匹配仍分别计次，后两步需要再次明确操作。

节点页展示每页 20 条历史；历史列表只列时间与操作种类，进入记录再核对当前状态，避免把旧状态冒充实时结果。记录页可以读取最新状态或取消排队／执行中的操作，即使生成服务关闭也保留这些能力。已存在后续记录时提供其入口，不因该后续取消或中断而再开一个分支消费。

## 阅读与视觉层级

两套主题共用同一业务结构与语义 Token：赛博主题使用深色面板、序号与线框强调；东方主题使用浅色纸面、衬线层级、印章和侧边线。不分叉账号、结果或操作逻辑。

桌面以主要材料区和条件／后续操作栏组织，窄屏顺序阅读。候选明确区分“尚非推荐”“建议优先查看”“备选”“本次不推荐”；显示频道、日期、时长、字幕语言与回退。匹配结果提供相关性、难度、时间、时效、限制、原字幕短引文与可跳转时间，以及实际抽样覆盖数。

没有视频、字幕仍在处理、没有可用字幕依据、没有合格推荐、失败、中断、取消与来源过期分别解释，不用空白卡或示例伪装结果。旧蓝图版本的材料只能作为历史阅读。失败后保留的上一步候选也明确标为旧依据，不宣称本次检查成功。

所有节点文字、视频元信息、模型解释和引文按普通 React 文本展示；不解释 Markdown 或插入 HTML。只有通过视频 ID 一致性检查的 YouTube 地址与数值时间戳可导航。访问链接不承诺当前可播放，不等于采用资源或证明掌握。

## 顶层实现与隐私

- 服务端 [resource-workspace](../apps/web/src/lib/agent/resource-workspace.ts)负责当前节点、账号隔离的分页、运行状态核对及精简视图；不依赖模型或 worker 密钥，不调用提供方。
- [节点入口](../apps/web/src/app/resources/nodes/[nodeId]/page.tsx)与[记录页](../apps/web/src/app/resources/[id]/page.tsx)使用真实登录与账号主题；返回路径携带具体节点，找不到旧节点时不创建空白替代品。
- [读取／取消操作](../apps/web/src/app/resource-actions.ts)每次重新认证并检查绑定账号，不把页面曾经登录当成当前授权；身份变化时隐藏私人内容。
- [客户端视图](../apps/web/src/app/resources/resource-view.ts)不含整份蓝图、其他目标、原始字幕任务 ID、完整字幕或 Skill 正文。浏览器只取得当前阅读所需的候选、短引文与条件。
- 新建运行仍走[已验证的独立执行接口](agent-resource-entry.md)，次数、唯一执行权、来源与永久后继约束没有在界面中重新实现为另一套规则。

本批无 SQL 变更、真实提供方消费、托管发布或历史数据迁移。状态读取可能按既有数据库规则处理过期租约，但不会发起新执行。
