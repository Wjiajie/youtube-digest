后续增量：[主动开启的播放位置同步](automatic-positions.md)在扩展可见面板内提供用户开启、每 30 秒保存变化位置的能力；手动流程继续保留。下文是原始手动批次的证据，不包含后续自动同步验收，也不代表持续后台观看统计。

Web `/progress/resume` 与扩展“学习 → 继续学习”共用双主题组件，接通上一批[学习位置云端入口](learning-positions.md)。本批交付的是明确保存与恢复位置，不是自动观看同步，也不是完整字幕／理解工作台；尚未托管发布。

## 用户可完成的流程

1. 从正式路径或成长档案进入继续学习；扩展需主动展开，才读取私人位置。
2. 选择节点下的视频，读取该资源的最新记录，核对来源及位置版本，再明确确认。较早、未进入最近 50 条列表的资源也能定向读取。
3. 手动填写整数秒，或者在扩展明确读取当前视频的位置。读取只填入草稿，不保存、不切换视频、不操作播放；广告、导航或身份不符时保留原输入。
4. 明确保存。其他设备已更新时拒绝旧版本，保留输入，重新读取并确认后才能再保存；不会自动用新版本覆盖。
5. 点击已保存记录的时间链接，打开原视频。历史记录保留原节点和视频归属，原地复用绑定或归档后不会把旧位置套给新视频。

零秒有效，也允许回看时保存较早位置。位置不代表观看时长、比例、完成或掌握，不创建学习会话、笔记、成果、自评或蓝图修订。

## 恢复与账号边界

私人草稿按账号与蓝图隔离，使用版本化本机存储和独占编辑锁。另一个同源标签页只读；取得编辑权后需重新读取并确认来源。浏览器缺少安全锁或无法读取恢复信息时停止编辑。损坏数据可先复制，再明确重置；存储写入失败不会发送未持久化请求。

发送前保存完整原请求；结果不确定时冻结输入，只有用户明确核对才重发同一请求。切换主题、任务、视频、收起面板或重载均不自动提交、不移动草稿。原来源归档后仍允许核对原提交，旧成功回执也不能替换另一设备更新的位置。账号切换／撤销后隐藏私人内容，迟到响应不进入新账号。
