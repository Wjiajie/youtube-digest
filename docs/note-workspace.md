# 双端私人视频笔记工作台

更新：2026-09-10；固定点 `0fc2870`。本地 P8 增量，接通上一批[云端笔记](learning-notes.md)，没有新增 SQL 或托管发布。

## 已接通的体验

Web 从成长档案或正式路径进入 `/progress/notes`；扩展从“记录 → 记录视频笔记”按需打开。两端共享 [NotesWorkspace](../packages/ui/src/learning-notes.tsx)，认证传输分别使用已有 Web Actions 和扩展后台，业务逻辑不按主题复制。

用户明确选择节点下的视频，填写原文和可选整数秒。保存位置只是用户提供的定位信息，不是观看、理解或完成证明。保存后可阅读最近 50 条私人笔记，通过安全的 YouTube 链接打开原视频及时间点；这是外部链接，不是读取或操纵当前播放器。

历史保留保存时的目标、阶段、节点、路径版本、原文及视频。当前来源已被移除时明确提示，但不重写旧记录。原回执恢复不会把旧笔记提升到较新记录之前。记录不自动变成成果证据或节点自评。

## 恢复与身份保护

- 草稿按账号与蓝图隔离，本机仅保存恢复信息，正式数据仍在服务器。换主题、切视频、切任务或收起面板，不移动关联来源，不卸载已打开的笔记编辑器。
- 原提交先持久保存，再发送。响应丢失时冻结编辑、保留同一提交标识与正文，只有明确点击才核对原提交；不自动重发或生成新标识。
- 版本冲突、失效绑定等明确拒绝保留原文，要求读取当前路径并明确重新关联。未确认结果的原提交不能用这种方式偷偷换来源。
- 同一账号／蓝图在同一浏览器来源内使用 Web Locks 独占编辑；另一标签页只读，明确接手后先刷新当前路径。Web 与扩展各自的本机草稿不会被描述成跨来源共享锁，云端重复提交和版本保护继续独立生效。
- 存储不可用时停止发送并保留本次输入；损坏的恢复内容可复制，明确确认后才重置。云端成功但本地清理失败时，不谎称“尚未发送”，保留可核对原请求。
- 账号异常隐藏私人内容，换账号重新挂载；延迟响应不写到新账号编辑器。读取不一致／过期蓝图或错误回执不宣称成功。

## 双主题与可访问性

共用语义颜色、圆角和字体 Token。赛博主题使用高对比控制台边缘，东方主题使用纸色、双线和衬线标题；信息结构一致。Web 桌面分为编辑与历史两列，窄屏和扩展为一列；长原文、无断点链接可换行。表单有可访问名称、键盘焦点，主要按钮与输入至少 44px；减少动态效果沿用设计系统，不增加动画或第三方视觉依赖。

首次截图检查发现默认面板内距与标题层级不足，已补齐正文留白、历史分隔和响应式标题，并重建双端复查。它不代表正式 3D 美术或完整人工读屏验收。
