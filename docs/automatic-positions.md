# 主动开启的播放位置同步

2026-09-11 · P8 本地增量 · 固定点 `2413166`。复用[继续学习工作台](position-workspace.md)及既有云端位置接口，不新增数据库、浏览器权限或后台追踪服务；不代表已托管发布。

## 用户行为

在扩展“学习 → 继续学习”中选择当前学习节点下的视频，读取并明确确认云端来源与位置版本后，用户可以开启本次自动保存。当前视频和资源绑定必须同时匹配，不能仅凭相同视频把记录写到另一个节点。未保存的手动输入必须先保存或清空；没有编辑锁、恢复信息异常或存在不确定请求时不能开启。

开启后，每 30 秒通过现有播放器读取路径获取整数秒，仅在位置变化时保存；允许回看后保存较早的位置，零秒有效。不触发播放或跳转，不推算观看时长、比例、节点完成或掌握，也不创建学习会话、成果或蓝图修订。

用户随时可以停止。收起继续学习、切换到其他任务页、文档隐藏、离开页面、切换视频／资源绑定、账号变化或读取失败都会停止，不自动恢复。关闭面板或重载后需要再次核对来源并主动开启。启动选择不写入本机存储，不会从旧偏好中恢复后台追踪。

这是可见学习面板内的位置辅助，不是持续后台观看统计。计时器受浏览器调度影响，不承诺精确到 30 秒，也不在关闭时冒险补发最后一次保存。停止前已经发出的请求仍可能完成，界面明确说明这一点。

## 一条保存流程

[共享工作台](../packages/ui/src/learning-positions.tsx)继续拥有唯一的草稿、编辑锁和提交恢复机制；自动采样不另建 outbox。每次发送前先保存不可变原请求，成功回执推进位置版本；下一次使用该版本，位置不变不重复写入。

跨设备版本冲突或来源失效后停止，保留采样位置并要求重新读取、明确确认，不自动重置版本或覆盖其他设备。响应丢失、回执不匹配等未知结果保留完整原请求，仅用户点击“确认原位置提交”时精确重发。存储失败则不发送未持久化请求；已发请求成功但本机清理失败时停止并保留恢复入口。

停止、隐藏、切换资源或账号后到达的取时响应不能启动新的保存。已发保存的合法回执可以完成原账号下的结算；账号卸载后迟到响应不会进入新账号。手动 Web 工作台不提供自动取时入口，原有保存与恢复语义保持不变。

扩展仍使用[现有受控读取器](../apps/extension/src/player-position.ts)：校验账号、扩展面板来源、当前活动 YouTube 视频及读取前后的页面身份；广告、直播、加载和不稳定时间被拒绝。本批未扩大该读取器的权限或视频支持范围。
