# 双主题环境构图试验

固定点 `2f6bd29`，P2 内部制作切片；本地实现及运行验证已完成，不是正式角色／商业美术验收，也不替代 P5 首页。

## 本批目标

- 开发专用 `/design/environment`，生产返回 404；从已有设计预览链接进入。
- 用户一次选择已取得的四个 Kenney Nature Kit GLB：`rock_largeA.glb`、`rock_tallA.glb`、`tree_pineTallA.glb`、`tree_plateau.glb`。仅 File API 本地读取，明确槽位，不上传、不请求模型外链、不保存账号、不随生产分发素材。
- 四件组合全部有效才替换场景。重复、遗漏、额外文件、总计超过 10 MB、无有效高度、外链、绑定或动画资产拒绝；失败保留原场景，清除或离页释放持有资源，迟到加载不能复活旧场景。
- 同一组真实环境候选分别形成东方山势／留白与赛博生态展台的构图、光照和表面框架对照。它们只是环境制作研究；相同自然素材不能作为两套完整主题成品的证据。人物席位留空，不造几何假人冒充用户。
- 可切换主题、标准／低画质及二维文字视图；DOM 控件和来源说明不依赖 Canvas。默认按需渲染，无自动旋转、风动或循环特效，减少动态效果不触发持续帧；提供手动轨道观察与重置镜头。
- WebGL 失败或丢失时明确降级，用户可重试；清除后可再次载入，不把“解析成功”写成“已显示成功”。

## 模块与验收

`loadEnvironmentKit(files)` 是本地四件资源接收接口，返回四槽 GLTF 集合；`disposeEnvironmentKit` 负责集合的唯一资源释放。Web-only 渲染模块借用集合，克隆场景节点但不拥有原几何／材质；主题与画质只改变构图／呈现，不重新读取文件。控制模块负责请求代次、替换、清除和错误状态。既有单件人物试装保持独立，不为内部工具引入数据库或通用场景编辑器。

已授权测试 seam 为公开资源接收／释放接口（真实 GLTFLoader）、隔离浏览器的实际文件输入／主题／降级／清除操作，以及生产设计页隔离。先红后绿，不用 Canvas mock 或常量快照替代实际画面。真实下载文件保留于忽略目录，不作为单元测试必需依赖；GPU 旅程明确要求本地四件文件。

完成证据需包含双主题实际 WebGL 截图、窄屏、低画质、无 WebGL 和清除／失败保留；记录真实渲染器，不把软件 GPU 截图当作 Mac mini M4 硬件 FPS 或正式网络预算。尚无完整人物、动画、最终材质／美术审批时继续保持 P2 进行中。

## 2026-09-10 验证结果

- 接收模块 6 项测试通过，使用真实 GLTFLoader 与独立构造的三角形 GLB；先复现重复文件被接受、总大小未在读取前受限、动画被静态组合接受，再逐项修正。实际资源 dispose 事件验证集合释放；外链、无有效高度等原约束继续通过。场景相关共 19 项测试通过。
- `check:m1` 通过：353 项 Vitest／34 文件、四工作区 TypeScript、既有账号升级、九阶段向导、Next 生产构建、云配置 WXT 构建与安全检查。扩展产物仍为 566.16 kB，没有新增场景依赖或权限。
- `npm run test:e2e`：34 项通过（10.2 秒），包括两个视口下新增设计路由的生产 404。生产路由清单出现路径不意味着内容被公开；实际 HTTP 检查为 404。
- `npx playwright test --config playwright.environment.config.ts`：最终 3 项通过（13.6 秒）。实际选取四个下载 GLB，双主题标准／低画质、320px、二维视图、缺件／损坏保留、清除与重新选择、真实 `WEBGL_lose_context` 后重试均通过。浏览器 getContext 返回 null 的能力测试确认无 WebGL 时仍有入口／回退；这是能力模拟，不是不同物理显卡验收。
- 减少动态效果下观察真实 WebGL drawElements：初始绘制稳定后 250ms 采样窗口没有新绘制，手动观察会重新绘制；不是帧率基准。文件读取延迟测试证明清除后迟到结果不恢复场景，随后可再次载入。
- 七张实际场景／窄屏／降级截图位于 `.goal-loop/evidence/environment/`，已查看。首次旅程因测试 `getByLabel` 精确匹配未找到画质控件而停止；页面可访问性树已有正确 combobox，改为角色定位后通过。没有修改产品行为来绕开失败。
- 实际渲染器为 ANGLE／Vulkan **SwiftShader 软件渲染**。无未捕获页面错误、外部资源请求或应用本地缓存。已知 Three.Clock 弃用警告保留；刻意禁用／丢失上下文时 Three 会记录预期上下文警告，不伪称控制台全无输出。

## 画面判断与下一步

首轮赛博画面暴露按高度归一化的宽岩石超出展台并遮挡中央席位，已增加占地尺寸限制，最终截图中央席位可见。两主题能验证不同构图和控件复用，但这组 Kenney 素材的硬折面、柱状岩石和简化树冠仍明显偏低多边形积木风；默认色块、雾层与水面也未形成目标山水质感。**不认可它们作为正式东方环境或最终赛博世界。** 没有用加载、测试通过代替设计验收。

保留 B2 为轻量性能／构图对照。下一步优先取得并比较 B1 风格化自然素材，以及适合用户代入的真实人物基础；在真实样片中处理岩层轮廓、树冠密度、材质明度与人物关系，不继续靠增加圆台／光圈掩盖资产不匹配。正式人物、完整主题世界、短循环动作、美术审批及硬件性能仍未完成。

实现使用 R3F 的[自定义 Canvas 接口](https://github.com/pmndrs/react-three-fiber/blob/master/docs/API/canvas.mdx#custom-canvas)捕获异步初始化失败并自行处理尺寸，实际帧通知发生在 Three 绘制调用之后；[WebGLRenderer 文档](https://threejs.org/docs/pages/WebGLRenderer.html)说明的资源释放与上下文能力用于本地恢复验证。渲染器借用原素材，切换主题／画质暂重建画布；这是制作工具取舍，不是正式首页的最终生命周期优化。
