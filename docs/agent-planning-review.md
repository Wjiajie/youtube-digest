# 规划记录与草案阅读

固定点 `9875833`，P6 用户阅读切片进行中。让用户从已保存的目标定义找到规划记录，恢复服务端保存的草案、查看周安排和依据、取消未完成运行；不重新调用模型、不直接改正式蓝图。

## 界面与权限契约

- 目标定义提供规划记录入口；记录列表按时间倒序、每页 20 项，仅取 ID 与日期。列表不使用历史表状态冒充当前状态，进入记录后用运行 RPC 核对新鲜度。
- 独立可收藏地址恢复单次运行。页面先验证真实账号再读取，所有交互绑定当前账号；换账号或身份失效时隐藏旧私有内容。未知 ID 与越权均不展示其他账号内容。
- 显示规划所依据的目标定义、来源修订、每周时间预算、假设、新建议路径与节点完成依据。已有目标与新增建议区分，不把整份蓝图快照中的旧目标称为新建议。
- queued／running 可取消并手动刷新；不轮询模型、不自动重试生成。断线时保留页面但注明不是最新状态；可重新读取。身份失败时不继续保留私人草案。
- ready 是已生成草案，不是已应用路径；stale 明确来源已变化，禁止宣称当前可应用。取消／超时说明不保证供应商免费，未知 token 不显示成零消费。
- 双主题共享内容与交互、不同容器和时间线表达；窄屏长文本不溢出，键盘与减少动态效果可用。不增加 3D 资产、分析正文事件或客户端持久缓存。

## 本批边界及验证

复用现有用户 RPC，读取／取消不创建服务端特权客户端或注入模型。服务端页面使用真实身份；交互通过绑定账号的 Server Actions，参照 [Next.js 服务端与客户端边界](https://nextjs.org/docs/app/getting-started/server-and-client-components)。测试 seam 是公开用户访问接口、React 交互，以及真实本地 Auth → 页面 → RPC 旅程；不模拟内部存储来宣称云端验收。

本批不新增付费模型配置、生成按钮或伪造成功示例。真正发起规划、将运行转为可确认提案、确认时的 Goal Brief／蓝图双来源原子校验、澄清对话和视频检索仍需后续实现；当前用户没有历史规划时展示诚实空状态。旧扩展升级安排之前不部署。
