# 可跳过的公开示例

批次基点 `c36d2eb`；P5 本地实现并验证，未发布。对应目标 UI/UX 规划 §4.0；正式双主题 3D 仍独立验收。

## 交付边界

- `/preview` 是独立公开阅读体验，直接打开不请求账号、数据库或 Agent；不因过期登录 Cookie 阻止阅读。代理仅为这个精确路径跳过会话刷新，不扩大私人路由权限。
- `/` 保持身份判断：已登录显示个人蓝图；无会话进入 `/preview`；Auth 故障仍显示可恢复错误，不能装成登出或抹去私人内容。
- 示例含一个“准备清晰的五分钟公开表达”的虚构目标、学习／实践／检查点／复盘四类节点及明确虚构的成果。所有内容预先编写，说明只是结构示例，不是保证有效的完整课程或已运行的 Agent 输出。
- 用户可切换双主题，展开／收起完整示例路径，查看示例节点与成果。每个有关个人状态的展示都处在明确“示例”区域；不调用真实确认、保存、资源检索或授权。
- 明确入口：“跳过示例，登录”到 `/login`；“建立我的目标”到 `/login?next=%2Fgoals%2Fnew`。仍是受邀测试，不承诺自助注册。
- 示例没有编辑框、缓存、自动数据导入或主题写入。页面预览主题不改变账号主题；先不跨登录保存预览偏好。示例成果、节点完成状态、人物装饰永不进入用户数据库。已登录用户访问根入口不会重复演示，主动打开 `/preview` 可阅读同一公开内容。
- 已实现能力与未来愿景分别标注：当前可定义目标、审阅路径、记录成果；Agent Skills、自动推荐、字幕工作台和正式 3D 未接通。原创静态身份视觉是回退，不作为商业美术验收结果。

## 模块与验证

Web-only `PublicPreview` 模块封装示例内容、临时主题与路径展开。接口为无参数 React 组件，不接受用户数据或服务器 Action。使用既有主题 Token／ThemeSurface／ThemePicker，不复制账号主题读写模块或私人 HomeDashboard，也不引入假网络 Adapter。

已授权测试 seam：公开 React 操作、真实 Next 页面／Proxy、真实 Supabase SDK 外部传输故障，以及隔离生产浏览器与本地 Auth。按 TDD 小步红绿推进：公开入口绕过外部依赖、私人路由不绕过、根入口身份分流、主题切换保留示例路径展开、无写入／缓存、创建跳转与真实账号不受污染。
