# 扩展中的学习与记录分区

更新：2026-09-10；固定点 `188f460`，实现 `2a44e98`，窄屏修复 `413e2f5`。P8 本地体验增量，不增加字幕、推理或播放追踪能力。

## 已实现体验

侧边栏不再把学习说明、资源列表、成果记录和节点自评堆在同一任务区。登录后默认进入“学习”，用户可切换到“记录”：

| 始终保留 | 学习 | 记录 |
| --- | --- | --- |
| 当前视频的明确绑定选择、目标／阶段／节点、返回原路径 | 学习用途、完成依据、预计投入、开始会话、其他可学习节点 | 私人成果、完成依据自评、各自原请求恢复与历史 |

两分区共用业务语义：赛博主题使用控制台边框与底边指示，东方主题使用页签／双线边框与衬线标题。复用语义 Token，不增加第二套数据或表单。没有空的“理解”页签；字幕、双语和讲解实现后才能开放该任务。

任务切换只隐藏内容，不卸载已打开的表单，也不触发新的私人读取、保存、学习会话或模型调用。原有按需入口继续保留。视频或主题改变不改选成果节点、不重置草稿和未确认提交；换账号立即移除前一账号私人表单，并从学习分区重新开始。面板重载后仍通过原有账号隔离恢复规则恢复草稿，而不是把页签选择当成学习进度。

## 模块与可访问性

[LearningWorkspace](../apps/extension/entrypoints/sidepanel/LearningWorkspace.tsx)只接收学习／记录两块内容，封装页签状态、焦点与持续挂载；[App](../apps/extension/entrypoints/sidepanel/App.tsx)继续拥有账号、视频上下文和动作。它不是新的通用组件框架，也没有改动共享成果或状态表单的保存规则。

页签具备可访问名称、选中状态、与内容区的双向关联和单一 Tab 入口。方向键循环切换，Home／End 到首尾，Enter／空格保留原生按钮操作。隐藏区不进入正常键盘顺序；当前内容区可以接收焦点。点击目标至少 44px，窄屏内容换行，无新增动画，并为强制颜色模式保留选中边框。
