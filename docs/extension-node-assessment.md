# 扩展中的明确节点自评

更新：2026-09-10；固定点 `aff4ebe`，源码 `4fc20c8`。P8 本地增量：在视频旁核对完成依据、明确保存节点状态，与 Web 复用同一套状态确认规则。观看、开始会话、切换视频均不会自动确认完成。

## 用户流程

“核对节点状态”按需打开私人路径与状态。用户明确选择节点，查看当前完成依据与原确认，再选择尚未开始、进行中或自我确认完成。确认完成前必须勾选已核对依据；可以关联同节点成果，也可以不关联，但未关联时明确显示这只是自评，不是掌握证明。没有视频的实践、检查点和复盘节点同样适用。

保存前持久化原请求。响应丢失时不自动重试或修改原提交；用户重新打开后通过“确认原提交结果”恢复原回执。路径或状态修订冲突要求重读并明确核对，不覆盖其他确认。历史保留当时的标题、预计投入、完成依据与自评修订。

收起、主题变化和视频导航保留当前选择／待核对请求；不会自动改选当前视频节点。切换账号立即隐藏私人表单，恢复信息按账号隔离。节点自评、私人文字成果与学习会话是三个不同动作，不互相自动触发。

## 设计与边界

- [侧边栏入口](../apps/extension/entrypoints/sidepanel/StatusPanel.tsx)只负责按需读取、失败恢复与账号生命周期，不另造状态表单。
- [共享确认模块](../packages/ui/src/node-status-workspace.tsx)继续负责完成依据勾选、修订冲突、原请求恢复、编辑锁与当前／历史展示；Web 语义不变。
- [扩展状态适配](../apps/extension/src/node-status.ts)通过已有 `/api/v1/node-status` 读取和确认，解析实际响应并核对回执。
- [共享认证传输](../apps/extension/src/authenticated-transport.ts)由成果与自评两个实际使用方复用，保持账号／Token 隔离、请求期限、禁止 HTTP 缓存和精确失败分类；网关通用错误不冒充确定拒绝。

当前快照与自评来源不一致时拒绝显示为可靠工作区，读取失败不等于没有记录。历史允许包含已改名、移动或归档节点，不能拿今天的上下文改写旧判断。可选成果读取失败仍可明确作出不关联成果的自评；身份失败则不继续展示私人工作区。

没有新增数据库迁移、浏览器权限、Agent 消费或自动重试队列；两主题使用同一共享结构与紧凑语义样式。当前界面提供可用的独立入口，不以空的“理解”标签伪装完整学习工作台。
