## 用户语义与状态

Goal Brief 是规划前的目标定义，不是已经拥有正式路径的 Goal。它记录目标、起点、期限、每周可用时间、约束和成功标准，不限定职业或学习领域。没有视频的目标同样有效。领域词义见 [CONTEXT](../CONTEXT.md)。

- 草稿允许信息未齐，不代替用户补写答案；明确确认需要目标、起点、每周时间和成功标准。未指定期限／约束作为待解释的不确定性保留，不捏造期限或声称没有约束。
- 每周投入以分钟表达，可为 1–10080；这是物理一周上限，不将首批用户的 3–8 小时画像硬编码为领域限制。文本保留原措辞，确认时排除仅空白的关键字段；日期必须是有效日历日期。内容自带版本，未知字段／版本被拒绝，防止旧客户端静默丢弃未来信息。
- 保存草稿或明确确认都会创建新的定义修订；保存修改后当前状态回到草稿，需要重新确认。确认只表示认可这一版定义，**不会创建正式目标、应用路径提案或改变蓝图版本**。
- 账号绑定的提交 ID 记录精确回执：断网重试同一请求返回原结果，不新增修订；相同 ID 改内容被拒绝。旧确认请求的重试可能返回旧确认回执，但不会把最新草稿重新确认为有效。未来 UI 必须区别“原请求已完成”和“当前定义仍已确认”。
- 后续 P6 只能使用用户选择的当前已确认定义，并记录使用的修订；用户继续修改后需要重新核对再规划／应用。当前尚无 Agent 运行与跨运行状态门禁，不把一枚 confirmed 状态宣称为完整 Agent 编排。

## 顶层实现与权限

复用 TypeScript／Zod、Supabase PostgreSQL 和现有账号绑定 Server Action。独立 `goal_briefs` 保存当前状态，不塞进正式 BlueprintSnapshot，也不要求先创建一个演示目标。新定义属于当前账号的蓝图；后续规划时再明确关联正式目标。

数据库将内容校验、版本条件、确认状态和回执原子提交；与其他蓝图修改共享根行的短事务串行点。并发相同请求只产生一次结果，两个不同请求竞争同一修订只有一个成功；不会锁住长时间 Agent 推理。补充索引支持账号读取和关联删除。

只有 Web 当前账号能读写定义。公开 RPC 为 invoker，窄写入位于 private，验证真实账号且拒绝所有 OAuth 客户端；没有把 user_metadata 当作授权依据。表开启 RLS，客户端只可读自己的当前定义，不能直写状态或查看 private 提交回执。原始目标、起点和标准不进入普通事件／日志。删除账号会级联删除定义与回执；当前没有用户删除／历史浏览／导出 UI，不能宣称这些隐私功能已交付。

应用层再次验证账号、输入和回执身份／修订／状态／内容。网关故障、畸形回执或错误记录不会被当作保存成功；版本冲突和输入错误保留受控含义。Web 卡片已接入本机草稿、未知结果恢复与多标签保护，数据库幂等不代替这些界面责任。

代码入口：[领域与准备度](../packages/domain/src/goal-brief.ts)、[应用服务](../apps/web/src/lib/goal-briefs.ts)、[Web Action](../apps/web/src/app/goal-brief-actions.ts)、[迁移](../supabase/migrations/20260909211441_goal_brief_definitions.sql)。先本地 DDL 验证，再 Advisor／CLI 生成迁移；已恢复校验函数→表→写函数的依赖顺序及显式 ACL，移除自动生成的无关 `pg_net` 删除和关闭函数检查语句。

## 双主题工作台

- `/goals` 展示当前账号的云端定义，每页 50 条，按更新时间／ID 排序。已有记录可按固定 URL 继续；空列表不插入示例。首页已有入口。列表翻页不是跨请求快照，其他设备在翻页期间更新时可以返回第一页重新读取。
- “定义一个新目标”分配固定页面 URL，并明确新草稿标记；此时不写数据库。普通已存定义 URL 若不可访问，显示未找到，不用空白覆盖。尚未云保存的定义需收藏原 URL 找回本机文字；本机草稿不宣称跨设备同步。
- 卡片列出目标、起点、每周分钟、可选期限／约束及成功依据；准备度说明已填写与待补充，关键内容齐备才可明确确认。未填可选内容会显示不确定性。未接通的 Agent 对话／路径生成明确说明，不展示假的生成或扣费。
- 赛博切角／网格、东方圆印／纸面与不同字体共用既有语义 Token。主题切换不重建表单、不丢焦点与文字；窄屏单栏，使用有标签的 DOM 控件、可见焦点与文字状态。
- 本机恢复以账号＋定义 ID 隔离，含格式版本与原提交。发送前必须写入精确请求；存储失败不发送。响应不明时锁定文字，仅允许核对原提交。拿到旧确认回执后仍读取当前云端修订；较新草稿不会被误标为已确认，也不会自动丢弃本机文字。
- 版本冲突需读取当前定义，展开云端文字后，明确选择保留本机文字并基于当前修订核对，或放弃本机修改使用云端。已知版本过期不继续宣称当前确认有效。
- 同一账号／定义使用 Web Locks；第二标签只读，关闭原页后明确接手并重新读取云端。锁不可用时只读。读存储失败或格式损坏时不覆盖原文；可复制损坏原文后明确重新开始。恢复文字与原请求不一致也按损坏处理。账号失效隐藏私人表单，保留本机恢复数据。

入口：[列表](../apps/web/src/app/goals/page.tsx)、[页面](../apps/web/src/app/goals/[id]/page.tsx)、[卡片与恢复](../apps/web/src/app/goals/goal-brief-editor.tsx)、[样式](../apps/web/src/app/goals/goal-brief.css)。扩展不加入目标创建功能。
