# 明确清除资源证据

2026-09-11 · P7 本地增量 · 固定点 `109d444`。这是应用数据库内的主动清理，不是账号删除、自动到期任务或内容授权证明。真实服务开关仍默认关闭。

## 用户可以做什么

在资源运行记录中选择“清除这条检索链的证据”，阅读不可恢复的范围说明，再明确确认。清除不要求模型、视频或字幕密钥，也不受执行开关限制。

- 从任意一层发起，都清除同一次 discover 及全部 captions / match 后继，以及这些运行的采用核验正文。
- 清除范围包括候选标题、频道、字幕、引文、匹配解释、供应商作业编号、捕获的蓝图输入、检索条件及起点／约束；采用记录同时移除核验结果和视频 ID。
- 正在处理的操作不能再保存迟到正文；未确认的采用提案变为拒绝。已开始的外部请求不保证停止或免费。
- 正式蓝图、已确认提案及修订、资源绑定、会话、笔记、成果和节点自评不被删除。提案与修订是用户决策历史，仍可能含目标正文和资源引用；此功能不宣称删除账号的全部个人数据或所有视频 ID。
- 清除后只展示清除时间、来源版本、节点／上下游及采用回执入口，不从正式路径重建第三方正文。

提交清除后立即隐藏当前页面的旧材料。网络失败或结果未知时只提供重新读取，不自动再次清除；旧的在途读取不能覆盖较新的清除结果。账号变化隐藏私人内容。其他已打开页面必须重新读取，本批没有跨标签页／离线副本实时撤回。

## 顶层设计与安全

内容生命周期与业务回执分离。资源运行及采用记录增加终态 `cleared` 和 `cleared_at`；数据库约束要求对应正文为 SQL NULL，读取器也拒绝残留正文、缺失清除时间或伪装为成功的空记录。

保留运行 ID、用户／蓝图／节点身份、版本、来源链、类型、创建／执行期限，以及采用的提案／绑定身份和原核验时间。租约、既有完成摘要和次数账本不因清理消失，旧 ID 只能恢复清除回执，不能再次执行。原偏好、起点或视频已清除，旧请求恢复不再比对这些正文；仍比对可保留的类型、节点、版本、来源和替换绑定身份。

清除、执行权申请、完成和提案确认使用同一蓝图锁串行化，清除整条链及采用记录在同一事务中完成。尚未执行的排队次数只退回一次，已取得执行权的次数不退款。迟到完成仍必须经过 worker 身份与原租约校验，只返回终态，不写入新的正文或摘要。已确认提案的精确重试仍恢复原修订，不重新修改路径。

Web Server Action 重新验证当前账号与绑定账号；数据库入口限定真实 Web owner。匿名、匿名登录、扩展及 worker 不能清除，用户没有表级直接写权限。新增公共函数为 invoker，必要的多表清理放在私有 definer 中，固定空 search path 并明确撤销默认执行授权。

主要入口：[账号绑定 Action](../apps/web/src/app/resource-actions.ts)、[运行读取与清除](../apps/web/src/lib/agent/resource-run-access.ts)、[最小展示投影](../apps/web/src/lib/agent/resource-workspace.ts)、[明确确认界面](../apps/web/src/app/resources/resource-workbench.tsx)、[清除回执](../apps/web/src/app/resources/cleared-evidence.tsx)、[增量迁移](../supabase/migrations/20260910164741_resource_evidence_clearing.sql)。
