# 来源绑定的选文讲解

2026-09-11 · 固定点 `fa797fe`。本批交付 P8 选文动作所需的内部讲解引擎与版本化 Skill，**尚无用户讲解入口、持久运行、额度或执行服务**。它不替代后续双端交互和商业验收，不作为已上线能力宣传。

## 当前能力

[讲解引擎](../apps/web/src/lib/agent/caption-explainer.ts)接收已核验的固定字幕页和明确选区。选区使用原始段落索引与 UTF-16 字符位置，最多五段、2000 字符，可附一条不超过 1000 字符的问题；结束位置不包含在选区内，不允许拆开 emoji 的代理对。系统从原文重建选文，不把浏览器提交的另一段文字当作依据。

发送给模型的只有选文、问题及有限邻近原文：选中片段前后最多各 256 字符，另含相邻段落靠近选区的最多 256 字符。不发送整页／整部字幕、账号、目标、节点、视频标识或标题。跨段保留原始段落和时间，不伪造句子间的完整论证。

[固定讲解 Skill](../apps/web/src/lib/agent/skills/explain-selection/v1/SKILL.md)分开表达“原文意思”“依据与解释”“可选的一般背景”“自测问题”和“局限”。材料不足可明确返回原因及所需上下文，不强制生成看似完整的回答。字幕和用户问题均按不可信数据处理，不成为系统指令；无工具调用、网页检索、资源推荐或任务执行，不声称用户已经掌握。

解释必须附一至三条来自实际提供片段的逐字引文，至少一条与选中的非空白文字重叠。未知段落、编造／改写引文、重复引用、只引邻段、仅碰到选区空白以及额外私有字段均拒绝，不能展示部分通过的结果。**引用位置正确只能证明文字来源，不证明解释的语义和事实正确。** 后续必须以跨领域真实样本做人工质量评估。

## 执行与数据边界

- 复用现有结构化推理策略：最多一次模型请求、无自动重试、60 秒生成期限、取消和明确的消费不确定性回执；错误与提供方警告不泄露选文、问题或密钥，关闭正文遥测。
- 用数据库观测时间及整个原文读取的单调耗时计算材料期限。已过期不开始、到期后不接受迟到结果；取消、来源到期和执行超时保持不同含义，不以本机墙上时间延长来源有效期。
- 原文、选区及问题在异步工作前冻结。系统生成证据摘要、问题绑定摘要、固定 Skill 版本／摘要和原始时间位置；模型不能生成或更换这些身份信息。重读时间不改变证据摘要，改问题会改变请求摘要。
- 这是内部推理模块，不是授权或保存服务。未来调用方必须先核验用户与资源、预留私有运行及额度，再调用引擎，并在来源原期限内保存后才向用户展示。当前不向 Web／扩展开放临时直调入口。

## 后续完整用户功能

1. **可恢复的云运行**：冻结来源／选区／问题、账号隔离、次数、唯一执行权和原请求恢复；继承源内容清除、到期及维护机制，不因翻译或讲解创建更长保留期。
2. **独立授权执行**：受控 Worker 与双端入口，准确绑定 Web／指定扩展身份；发起、核对和取消分开，关闭生成仍能处理已有运行。不放宽其他 Agent 权限。
3. **双主题上下文动作**：放在“理解”中，用户选中原文后核对选文并明确提问／讲解；键盘与触控有等价入口，不增加永久聊天标签。沿用赛博工具面板与东方书页表达，不复制业务。
4. **连续性与失败恢复**：保留选文、问题及未提交状态；切主题／任务视图不丢草稿，换账号／视频不显示旧正文。来源到期隐藏派生正文；失败可明确重试，未知结果先核对，不悄悄新增消费。
5. **发布前验收**：双端实际旅程、长字幕及窄屏、键盘／触控、内容权利／处理商及备份删除、真实语义质量、原生 Side Panel 与托管环境。当前均未因引擎测试通过而关闭。

本批不改数据库、Worker、HTTP、权限或 UI，不声称新增浏览器／托管验收。完整 P1–P9 目标仍以[执行路线](execution-roadmap.md)为准。
