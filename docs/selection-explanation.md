# 来源绑定的选文讲解

## 当前增量：双主题选文工作区

2026-09-11 · 固定点 `c72505b`。Web 阅读页和扩展“理解”现已接入同一个[选文工作区](../packages/ui/src/explanation-workspace.tsx)：从原文选择连续片段，核对选文、补充问题，再明确发起讲解。赛博主题采用工具面板与分区线，东方主题采用书页、印记与旁注；[样式](../packages/ui/src/learning-transcript.css)不分叉业务，也不新增永久聊天页签。

支持浏览器原生选文，以及可由键盘或触控操作的整段选择按钮。一次最多同页五段、2000 个 UTF-16 字符，问题最多 1000 字符；不拆开 emoji、不提交另一份字幕。整段按钮将焦点带到选文工作区，较长原文可使用原生选区限定片段。解释按原文意思、依据与引文、可选一般背景、自测及局限分层；材料不足是明确结果，不用生成内容冒充事实或掌握证明。

[共用校验](../packages/ui/src/explanation-view.ts)与服务端使用同一套[纯证据规则](../packages/domain/src/explanation-evidence.ts)，服务端另保留哈希与提示构建，不将 Node crypto 或服务器凭据打包到客户端。Web 使用同源 Cookie，扩展使用指定 OAuth；每次查找、发起、核对和取消都显式携带来源／选区／问题上下文，不依赖适配器记住上一页。问题只在 POST 正文中传递；响应有字节、UTF-8、时间与来源限制，扩展还核对前后账号、标签页、节点和字幕。

### 连续性与消费边界

- 当前账号／视频只保留一份内存草稿。切主题、学习任务视图或重新核对字幕不丢问题；返回窗口时先隐藏旧材料，明确重读后才恢复展示。分页后可返回原草稿，账号／视频变化不会展示旧正文。
- 草稿、字幕和答案不写入浏览器存储。关闭或刷新页面不保留未提交问题；重新选择同一来源和问题后，可查找已经提交的云运行。这里不承诺跨设备恢复未提交草稿。
- 原文及讲解均以服务端观测时间减去整个读取耗时计算期限。草稿即使暂时隐藏也会独立到期，清除回执删除旧选文／问题，取消后的迟到回答不能覆盖现态。
- 生成前先查找原请求；恢复只读，未知结果保持同一请求编号，只有明确终态后才允许新的重试。服务明确返回“讲解尚未开启”时，首次未执行草稿仍可编辑；如果此前已有不确定请求，不能用关闭开关推断它没有执行。默认开关、账号额度与服务端权限不在本批改动范围。

## 历史增量：双端 HTTP 与来源核对

2026-09-11 · 固定点 `c90f5da`。本地已接通 Web Cookie 与指定扩展 OAuth 的讲解入口；**双主题选文界面、实际 MV3 交互和托管发布仍待实现／验收**。这不是已上线的完整学习功能。

[公共入口](../apps/web/src/lib/agent/explanation-http.ts)把明确发起、读取、原请求查找和取消分开。查找使用只读的 POST 正文，不将私人问题放入 URL；发起和取消只返回编号与状态，不返回内部执行回执。响应禁止缓存，仅发起可能调用模型；关闭生成后仍可核对和处理历史运行。输入只接受已定义字段，实际 JSON 上传最多 32 KiB、等待最多五秒，不能由客户端提交字幕、模型、Skill 或另一用户身份。

[独立身份核验](../apps/web/src/lib/agent/explanation-http-identity.ts)验证签名声明与当前 Auth 用户。Web 只接收 Cookie，同源写入，拒绝 Bearer 或 Cookie 中的 OAuth 身份；扩展只接收配置中精确匹配的 OAuth Bearer，不回退使用 Cookie。身份验证以及读取／查找／取消各受十秒整体预算约束。用户侧数据库访问使用核验后的原 JWT，不使用管理密钥，也不扩大旧 Agent 或 OAuth 权限。

[最小结果投影](../apps/web/src/lib/agent/read-explanation-run.ts)只返回账号、运行／来源身份、状态、原始选区、问题和有限答案，不返回整页字幕、Skill、模型或内部指纹。即使仍在排队，返回问题前也重新读取原字幕，核对节点、版本、内容与期限；读取字幕和最后核对的网络耗时都扣除。再读取一次运行以识别途中的取消／清除，不把之前的答案重新显示。清除回执没有选区、问题或答案。

## 历史增量：独立授权执行

2026-09-11 · 固定点 `0605f7f`。本地新增[讲解执行编排](../apps/web/src/lib/agent/cloud-explanation-runner.ts)、[独立 Worker](../supabase/functions/explanation-worker/handler.ts)与[服务端配置及传输](../apps/web/src/lib/agent/explanation-runtime.ts)。**公共 Web／扩展 HTTP 入口和双主题选文界面仍待接入**，本批不把内部执行链当成用户功能上线。

独立 `BLUEPRINT_EXPLANATION_ENABLED` 默认为关闭；讲解使用自己的服务端随机凭据和账号次数，不继承翻译或资源开关。Worker 同时验证签名、当前 Auth 身份及服务端凭据，只接受 Web 或配置中明确指定的扩展身份；不能提交任意用户或任意 RPC。管理密钥仅留在 Edge，不加入 Web／扩展。上传限制为实际 128 KiB，超过限制或停滞、非严格答案及异常 Unicode 均拒绝；数据库继续负责原文、引用、租约与期限的最终校验。

编排先建立已授权的私有运行，再读取固定 Skill、唯一领取及单次推理。开始与领取的不可变来源、页面、选区和问题必须完全对应；生成使用领取时数据库观测时间扣除整个领取往返的单调耗时，不修改持久原文。普通读取、查找、取消和预留各有 10 秒请求期限；预留途中用户取消时，尽量取得已确认的排队结果再取消退额，响应未知不盲目重试。

推理期间每秒核对运行状态，单次观察最多五秒；取消、清除或观察失效会停止等待模型。执行期限早于原文时记为执行超时，原文更早或同时到期时保留来源过期语义。保存只提交原领取对应的答案与消费回执；确认响应丢失时，只重发同一租约、同一内容一次，不重新领取或生成。恢复只读既有运行，不能用恢复动作新增消费。网络超时不会误记为用户主动取消。

可用[本地执行验收脚本](../scripts/test-explanation-execution.mjs)启动独占的临时 Edge 进程，运行真实 Auth／PostgREST／SDK 与回环提供方；脚本移除自己的临时凭据并保留原有本地服务，不部署到托管环境。调用命令：`bash scripts/with-m1-runtime.sh node scripts/test-explanation-execution.mjs`，本机 CLI 可通过 `BLUEPRINT_SUPABASE_BIN` 指定。

用户明确发起时，数据库从其已绑定资源读取固定字幕页，校验原始段落与 UTF-16 选区，冻结问题和来源期限。浏览器不能提供另一份字幕、用户身份、模型或 Skill。Web 与指定扩展身份可建立、读取、查找及取消自己的运行；其他 OAuth、匿名用户和跨账号访问均不能取得正文。创建同一编号和相同请求只恢复，不再次扣次数；换选区或问题必须使用新的明确请求。

扣次数前还会检查最终紧凑 JSON 提示的实际字节数，包含控制字符转义，不只统计选中文字数；数据库与引擎共用 32 KiB 上限。模型正文中的不完整代理对和 NUL 明确拒绝，不把无法持久保存的文本报告为讲解成功。

只有内部服务能领取和保存：领取时冻结 Skill 版本／摘要及模型，同一运行最多领取一次。账号默认无讲解额度，未配置不能生成；每账号最多一个在途讲解。排队取消、到期或清除退回一次，已领取则保留可能消费的事实，不退回次数。排队与执行各有最多 120 秒期限，并受原文更早的到期时间约束；推理本身仍使用 60 秒单次请求策略。材料不足也是可恢复的明确结果，而不是传输失败或虚构答案。

[回执解析与执行适配](../apps/web/src/lib/agent/explanation-run-worker.ts)在保存前核对领取时的选区、问题、来源摘要和 Skill。数据库再次以实际原文检查回答格式及逐字证据；保存只接收答案与消费回执，不接受模型生成的来源身份。推理与读取共用[证据重建规则](../apps/web/src/lib/agent/explanation-evidence.ts)，避免恢复时绕过选区和引用限制。UTF-16 与 PostgreSQL 字符位置明确转换，不拆开 emoji；引用匹配依然不代表语义正确。

清除原字幕时，同一事务清除讲解的原文页、选区、问题、答案、Skill 与模型。到期或绑定失效也不能重新展示；迟到完成不能复活正文。保留运行身份、状态及不透明请求指纹，用于核对原请求、避免重复消费；指纹不是匿名化证明，不应进入普通分析事件。正式蓝图、用户笔记和学习历史不因清理派生讲解而删除。数据库备份、日志、处理商副本和持续托管维护仍需独立治理。

## 当前能力

[讲解引擎](../apps/web/src/lib/agent/caption-explainer.ts)接收已核验的固定字幕页和明确选区。选区使用原始段落索引与 UTF-16 字符位置，最多五段、2000 字符，可附一条不超过 1000 字符的问题；结束位置不包含在选区内，不允许拆开 emoji 的代理对。系统从原文重建选文，不把浏览器提交的另一段文字当作依据。

发送给模型的只有选文、问题及有限邻近原文：选中片段前后最多各 256 字符，另含相邻段落靠近选区的最多 256 字符。不发送整页／整部字幕、账号、目标、节点、视频标识或标题。跨段保留原始段落和时间，不伪造句子间的完整论证。

[固定讲解 Skill](../apps/web/src/lib/agent/skills/explain-selection/v1/SKILL.md)分开表达“原文意思”“依据与解释”“可选的一般背景”“自测问题”和“局限”。材料不足可明确返回原因及所需上下文，不强制生成看似完整的回答。字幕和用户问题均按不可信数据处理，不成为系统指令；无工具调用、网页检索、资源推荐或任务执行，不声称用户已经掌握。

解释必须附一至三条来自实际提供片段的逐字引文，至少一条与选中的非空白文字重叠。未知段落、编造／改写引文、重复引用、只引邻段、仅碰到选区空白以及额外私有字段均拒绝，不能展示部分通过的结果。**引用位置正确只能证明文字来源，不证明解释的语义和事实正确。** 后续必须以跨领域真实样本做人工质量评估。

## 执行与数据边界

- 复用现有结构化推理策略：最多一次模型请求、无自动重试、60 秒生成期限、取消和明确的消费不确定性回执；错误与提供方警告不泄露选文、问题或密钥，关闭正文遥测。
- 用数据库观测时间及整个原文读取的单调耗时计算材料期限。已过期不开始、到期后不接受迟到结果；取消、来源到期和执行超时保持不同含义，不以本机墙上时间延长来源有效期。
- 原文、选区及问题在异步工作前冻结。系统生成证据摘要、问题绑定摘要、固定 Skill 版本／摘要和原始时间位置；模型不能生成或更换这些身份信息。重读时间不改变证据摘要，改问题会改变请求摘要。
- 这是内部推理模块，不是授权或保存服务。未来调用方必须先核验用户与资源、预留私有运行及额度，再调用引擎，并在来源原期限内保存后才向用户展示。当前不向 Web／扩展开放临时直调入口。

## 后续完整用户功能

1. **可恢复的云运行**：冻结来源／选区／问题、账号隔离、次数、唯一执行权和原请求恢复；继承源内容清除、到期及维护机制，不因翻译或讲解创建更长保留期。
