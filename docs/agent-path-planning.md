## 本批结果约定

应用读取当前账号的已确认 Goal Brief 与蓝图后，调用单阶段规划器。模型只看到该目标定义、起始日期和规划规则，不读取用户其他目标，不拥有数据库、网络检索或正式确认工具。输出先经过真实 AI SDK 结构解析，再进行依赖、每周预算和期限检查。

模型使用候选内部节点 key；正式 UUID、现有目标保留、蓝图版本和资源空绑定由应用负责。成功返回待审阅草案、周安排、假设、Skill 正文／版本／摘要、来源 Goal Brief 修订与蓝图版本。周安排是待确认的工作量预算，不是假定用户每天都有空的日历。

每节点提供投入分钟、行动说明、完成依据和前置依赖。依赖只能指向候选内已经列出的节点，且不能安排在依赖之前的周；每周总分钟跨 Stage 合计不超过用户确认预算，节点周起始不晚于目标期限。支持通用四类节点，不硬编码职业领域或强制所有目标拥有同一种节点组合。

当前选择 AI SDK `7.0.97` 的 `ToolLoopAgent` 与结构化输出，Node.js 22 以上；只接受应用注入的模型对象，不使用字符串触发默认 Gateway。实际 Skill 位于 [plan-path/v1](../apps/web/src/lib/agent/skills/plan-path/v1/SKILL.md)，由固定路径加载并计算 SHA-256，不能由用户文字选择文件。内容基于[既有方法研究](agent-skill-research.md)独立编写，不复制第三方 Skill 全文；加载一个版本化规划 Skill 不等于完成全部 Skill 编排。

## 保护与明确缺口

- 输入未确认、归属蓝图不匹配、已过期限或当前蓝图已达 12 目标上限时，不调用模型。调用者必须从已认证账号读取真实记录；本内部模块不是鉴权端点，不能信任浏览器自报 `confirmed`。
- 单次生成、无自动供应商重试、无工具，限制 12,000 输出 token、最多 128 个节点、26 周，生成等待最多 60 秒。结果不完整或不合法时不生成可用草案；取消后迟到结果也丢弃。
- 返回可用 token 用量；未知用量保持未知，不当作零消费。取消／超时不保证供应商停止计费；不响应取消的迟到调用不会更新结果，用量需未来账务层核对。
- 显式退出 SDK 全局遥测；在本次模型边界去掉供应商警告原文，不改全局日志设置。原始提示、模型文本、推理和供应商错误不由本模块写入普通日志或错误返回；未来接入方仍须审查供应商自身与平台的自动采集。
- 固定 Skill 内容与摘要纳入结果；未来持久化需要保存完整运行检查点，不只保存蓝图投影而丢失周安排和来源信息。
- 本批不新增 Web/API 调用入口、不接付费模型、不保存云端运行或正式提案。目标澄清对话、租约／额度预留结算、取消续跑持久化、前端审阅和真实 DeepSeek 适配仍待后续切片。
- 发布前必须完成账号／额度入口、服务端 Skill 打包追踪、来源修订再次核验、并发／幂等和旧扩展版本安排。20 项跨领域评测及人工质量门槛仍未完成。
