# 扩展中的目标学习上下文

更新：2026-09-10；固定点 `8141692`。P8 本地增量：在 YouTube 旁明确“为什么学、要留下什么证据、如何回到原路径”。不是完整字幕／理解工作台，也没有托管发布。

## 用户体验

当前视频只有一个正式绑定时，直接展示所属目标、阶段和节点；同一视频用于多个节点时，必须先选择本次学习节点，不能静默归到第一个。页面呈现节点原有说明、完成依据和预计投入，不生成虚构推荐理由。旧路径缺少这些字段时明确提示尚未填写。

“开始学习”只创建活动会话，不代表完成或掌握。“返回此节点路径”打开配置中的 Blueprint 主站并定位原目标／节点，不接受任意跳转地址。没有匹配的视频仍可打开现有私人记录或返回 Web 选择路径。

主题切换与同一视频刷新保留有效选择；更换标签页、视频或账号会重新核对，等待期间不允许把新视频记到旧节点。读取失败保留恢复入口，不继续提供旧上下文动作。缓存内容明确标记，服务端仍负责最终写入权限与绑定有效性。

已有成果记录不会自动随选择或视频迁移。用户仍需核对记录表单的关联节点；同账号导航和主题变化不卸载草稿，切换账号立即隐藏上一账号内容。会话与私人文字记录是不同操作。

## 顶层设计

- [视频上下文投影](../apps/extension/src/runtime.ts)从正式快照与当前规范视频 ID 返回全部绑定及真实节点元信息，兼容旧快照的空缺值。
- [扩展后台](../apps/extension/entrypoints/background.ts)在开始会话和返回路径前重新核对账号、活动标签页、视频与所选绑定；后端保护不依赖侧边栏按钮状态。路径地址只由配置站点和验证后的标识生成。
- [侧边栏](../apps/extension/entrypoints/sidepanel/App.tsx)使用原生 DOM 控件与共享主题 Token，维护按账号／标签页／视频隔离的临时选择；旧请求不能覆盖新视频界面。
- 已有成果模块、会话原命令重试与账号隔离缓存继续复用。没有新增 SQL、云端接口、浏览器权限、供应商调用或完整 3D 依赖。
