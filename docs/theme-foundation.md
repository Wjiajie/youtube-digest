# 双主题 DOM 基础：接口与验证

2026-09-09。范围是 P3a 设计系统切片，不是 P3 全量完成或正式双主题美术验收。

## 已落地的模块接口

- `@blueprint/ui/theme`：只包含内置、版本化主题数据和 `ThemeSurface`。输入是主题 ID 与舒适／紧凑密度，输出同一个 DOM 容器；不得以主题作为子树 key。它不知道账号、蓝图或学习状态，也不执行场景加载。
- `resolveTheme`：从未知持久化数据解析 `{ id, version: 1 }`，未知 ID／版本回退赛博默认表现；不加载任意主题地址。未来偏好读写由宿主负责，本轮没有新增本地偏好事实来源。
- `@blueprint/ui/theme-picker`：原生、带标签、受控选择器，由宿主提供值与变更处理；不会保存蓝图或提交所在表单。
- `@blueprint/ui/styles.css`：共享 Panel、Button、Status、焦点与表单样式。Web 与扩展不再各自定义一套基础控件颜色；布局仍由宿主负责。

赛博使用深色技术排版、冷色边缘与层次；东方使用纸色、衬线标题、侧边框与印记式序号。成功、错误、警告、进行中、待同步各有语义 token，东方强调色不再兼任成功色。两套 CSS 都随轻量共享 UI 加载，不存在异步主题 CSS 失效；Web 场景需以后由单独的 Web-only 模块按需加载，不能进入此包。

## 本地设计预览

从仓库根执行 `bash scripts/with-m1-runtime.sh npm run dev --workspace @blueprint/web -- --port 3100`，访问 `http://localhost:3100/design`。需要已有本地 Web 环境配置；本页本身不调用模型或写数据库。

包含路径、私人记录、确认状态与紧凑学习侧栏的同一套控件样本。所有内容标为内部样本，不伪造真实保存、视频播放或个人成果。输入只留在当前页面，刷新后丢弃。生产构建通过服务端 `notFound()` 隔离，测试确认 `/design` 返回 404。

- 新主题界面测试遵循 red→green：先观察缺失模块／解析器的失败，再实现；验证未提交输入、焦点、确认状态保留、未知版本回退和选择器不提交表单。
- 真正的 `BlueprintEditor` 在两主题往返后保留草稿、DOM 节点、文字选区；真正的扩展 App 保留学习上下文与成功提示，切换不发起额外浏览器业务消息。未以内部模块 mock 代替业务实现。
- `npm run check:m1`：10 个文件／30 项测试、TypeScript、PGlite 迁移契约、向导校验、Web／WXT 构建与扩展安全检查通过。云配置扩展输出总计 466.46 kB，本轮无 3D 包或资产。尚未增加通用的传递依赖导入图禁止规则。
- `npm run test:e2e`：桌面／移动 Chromium 共 12 项通过，包括生产预览隔离。邮件测试使用受控响应，不发送真实邮件。
- ego-browser 空间 1 实际运行：开发页和登录页有内容、无框架错误覆盖层；两主题切换保留输入与确认；320 CSS px、减少动态效果条件下未横向溢出；东方主题标题使用衬线字体，焦点轮廓可见。鼠标辅助点击未生效时改用同一 DOM 控件事件完成验证，没有修改业务状态或注入会话。完整跨页面键盘旅程仍待后续测试。
- 配色对比度计算：以当前 token 与表面合成色核算，正文／状态最小比值为赛博 6.37:1、东方 5.68:1；主按钮文字为 9.44:1／6.82:1；表单边框对字段背景为 4.51:1／3.91:1。赛博透明表面采用其最亮背景端点合成。这不是对所有未来背景、图片、禁用控件或完整 WCAG 合规的认证。
