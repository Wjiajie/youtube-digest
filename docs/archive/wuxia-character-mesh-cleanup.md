## 本轮目标与范围

根据用户标注，先修眼周不平整和背发杂乱，定位侧脸黑痕来源。使用当前 4K PBR 模型作为输入，新文件输出，保留原版。未修改产品代码、未安装 Blender、未调用收费 API。

## 诊断结论

- 灰模上圈出的尖锐隆起主要位于上眼睑／睫毛带，不能当眉毛整体削平。平滑区域围绕双眼上缘，保留眼形并限制位移。
- 以位置合并 UV 接缝后，源模型有 39 个连通分量，主体占 1,206,319 面；多数杂乱发片与主体相连，删除孤立块无法根治。
- 用户指出的侧脸黑色划痕在灰模中不明显，但纯基础色模式仍清晰可见。因此明显黑痕包含基础色贴图污染，不能靠删除皮肤几何解决；本轮没有修掉这些贴图黑痕。

## 处理方法

1. 在局部计算中按 1e-6 坐标精度识别重合顶点，避免 UV 接缝分裂造成平滑裂缝；输出仍保留原顶点及 UV 布局。
2. 眼周有限次局部平滑，最大位移约 0.003 模型单位。背发按空间范围和参考贴图亮度限定，最大位移约 0.012 模型单位。模型高度为 2 单位，这些值不是已校准的物理毫米数。
3. 仅删除背发指定区域中的 36 个独立小分量，合计 311 面；不按全身统一大小阈值删除耳饰和其他饰品。
4. 对新增面积塌陷或法线翻转局部回退位移；最终候选完成 21 次局部限制迭代。修改区域及直接相邻面的顶点法线重新计算。
5. 贴图、UV、材质原样保留，没有锐化、图像重绘或 PBR 法线重烘焙。

局部模型虽保留 UV，因表面发生位移，仍可能产生局部纹理拉伸；原法线图也可能继续显示旧表面的细碎噪声。此版本适合检查网格改善，不等同于完成纹理精修。
