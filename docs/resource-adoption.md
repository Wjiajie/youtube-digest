# 明确采用与替换学习资源

更新：2026-09-10；本批固定点 `4956655`。在本地实现匹配建议 → 单视频重新核验 → 不可改写的提案 → 用户确认／拒绝 → 正式资源绑定。赛博与东方两套主题共用业务流程。默认关闭，尚未部署或调用真实提供方，不代表完整 P7 已交付。

## 用户可见结果

仅当前匹配记录中的推荐或备选可发起采用。已有资源时必须明确选择新增或替换；每个节点最多 16 个绑定，不重复添加同一个视频。点击后立即出现采用记录入口，网络结果未知也保留恢复地址，不自动重试。

重新核验只查所选视频一次，不再次搜索、不读取字幕、不调用模型。视频必须仍满足原地区及筛选条件，标题、描述、频道、时长、语言、字幕可用性等匹配依据必须与来源一致；变化时要求重新检索与匹配。平台热度变化不使教学内容自动失效。这不是实时播放保证或质量认证。[YouTube videos.list](https://developers.google.com/youtube/v3/docs/videos/list)

通过后生成提案，正式路径保持不变。采用页展示所选视频、对应节点、变更前后绑定和核验有效期；用户明确确认才写入正式路径，也可以拒绝。核验窗口为十分钟，确认时数据库再次检查来源与版本。过期提案仍可阅读／拒绝，不能确认；重新核验必须另行主动发起。

替换创建新的绑定 ID，旧绑定归档，已有学习会话仍归属于原视频。未被选择的资源、其他节点、学习状态保持不变；绑定视频不会把节点标为完成。确认响应丢失时，读取原记录可以恢复已应用版本，不重复写入。

## 顶层设计

- [视频核验器](../apps/web/src/lib/resources/verification.ts)复用固定来源、有界时间／响应体的适配器；只接受服务器保存的候选和条件，不接受客户端“验证成功”证明。
- [采用编排](../apps/web/src/lib/agent/cloud-resource-adoption.ts)串联次数预留、唯一执行权、核验和不可变回执。只有存储回执允许原样重试一次，供应商请求不重试。
- [增量迁移](../supabase/migrations/20260910113909_resource_adoption.sql)添加账号隔离的采用记录与私有次数／租约；通过既有最终提案写入入口做原子来源校验，旧通用接口不能绕过核验。
- [工作区投影](../apps/web/src/lib/agent/resource-adoption-workspace.ts)只下发当前节点的变更，不发送整份蓝图、Skill、原始字幕或完整匹配任务。所有读取／写入重新认证，账号变化隐藏私人材料。
- [采用界面](../apps/web/src/app/resources/adoption-review.tsx)复用主题 Token 和资源工作台结构；读取、取消、拒绝、确认不需要提供方配置，也不会触发新核验。

新增 `BLUEPRINT_RESOURCE_ADOPTION_ENABLED` 默认关闭，独立于检索开关。启用需要服务端 YouTube 与资源 worker 凭据，不需要模型或 Supadata 凭据。私有核验次数默认零，启用不等于发额度。次数不是人民币账单；取得执行权后失败／取消不保证没有用量，只有排队状态取消、到期或来源失效才退回预留。
