# 目标澄清：受控单轮引擎

固定点：`ab4f25a`。这是 P6 对话旅程的内部运行切片，**不是已经上线的聊天功能**。后续已本地连接[云端会话与回合](agent-clarification-sessions.md)，本页下方历史证据保留原批次边界。目标与交互依据见[目标澄清设计](target-ui-ux-plan.md)、[Skill 研究](agent-skill-research.md)和[目标定义](goal-briefs.md)。

## 本批契约

- 输入是应用读取的一个已保存、未确认的 Goal Brief 修订，以及当前用户回答、应用选择的有限历史对话。用户不能选择 Skill、文件、模型地址或工具。
- 云端增量允许应用另行传入当前工作摘要；推理基于工作摘要继续，来源 ID 与修订仍指向真实保存的 Goal Brief，不把 Agent 修改伪装成已保存来源。
- 固定版本的 `clarify-goal` Skill 采用反映、开放问题与总结，引导通用目标，不用职业领域白名单，也不机械遍历问卷。
- 一轮只返回一个聚焦问题，或者无问题的待审阅摘要。必要信息仍有缺失或存在阻碍规划的疑点时须追问，除非用户明确要求暂停；暂停必须有本次原文引用且不夹带追问，不会冒充准备完成。期限和约束可以未知。
- 模型只提议字段修改，不重新生成整份摘要。每个修改携带本次用户回答中可定位的原文依据；不允许重复字段、伪造引用或用历史回答覆盖当前草稿。未修改的字段原样保留，清除字段也必须有本次回答依据。
- 引用存在只能证明文本可追溯，不能机械证明语义正确。摘要和引用必须留给用户核对，不能宣称机器已经杜绝幻觉。成功标准是否有意义、问题是否真正单一仍需真实质量评测。
- 返回值区分需要输入、用户暂停与可供审阅，同时列出必要缺项、可选未知和模型疑点。可供审阅不是已确认；不保存 Goal Brief、不运行规划、不写正式蓝图。
- 结果包含来源修订、当前回答 ID、Skill 版本与哈希，供后续云端运行固定来源。只接受应用选定的 Skill 哈希，不符合预留版本时在模型调用前拒绝。
- 输入、历史和输出有大小限制；单次结构化生成、不自动重试、60 秒上限，支持取消（包括供应商忽略取消），失败不返回用户正文或原始供应商错误，普通日志与遥测不记录正文。

## 原引擎批次的验证与后续

本批通过真实 AI SDK 的结构解析与外部模型夹具验证上述运行契约；不将夹具当作真实 DeepSeek 对话质量、费用或线上用户验收。

后续须连接独立云端会话与回合记录、身份隔离、并发执行权、额度、超时恢复，以及双主题对话／直接编辑／明确确认旅程。沿用 Node 推理、Edge 特权写入的职责，不把管理员密钥放入 Web。用户直接编辑或其他会话修改来源后，旧回合结果不得覆盖新内容。已确认定义需用户主动进入编辑后才能继续澄清。

历史窗口本批最多 12 个完整问答对，不静默裁剪；到达窗口上限时返回输入不合法。未来会话服务必须展示可恢复的摘要交接／新轮次入口，不无限重试同一超限请求。账号、恢复和持久化完成前不开放生产调用入口。
