# 受控资源匹配 Skill

更新：2026-09-10；固定点 `08e2858`。P6/P7 内部运行切片，接在[候选检索](resource-discovery.md)之后；尚未接入用户入口、云端运行或实际供应商消费。

## 用户结果与当前边界

目标是让每个需要学习材料的 Path Node 获得可解释的选择，而不是把搜索第一条当成推荐。当前内部运行器已支持最多一个默认推荐、两个备选，或明确全部拒绝。每条候选分别解释相关性、难度、语言、投入时间和时效，附带限制与字幕引用。模型不能新增候选、生成 Resource Binding 或改变路径。

输出始终是**待人工审阅的建议**。引用确实出现在字幕中，不等于解读正确、教材可靠或视频适合用户；正式采用、真实质量评测和进入视频前重新验证仍未完成。

## 输入与证据

运行器校验传入蓝图和检索来源的蓝图 ID、版本、节点 ID，节点必须存在且为学习类型。输入在异步调用前解析为独立副本，避免调用期间的外部修改改变本次依据。仍需未来服务端调用者认证账号、读取当前版本及服务器保存的检索记录，不能把客户端提交的快照或“可匹配”标记当成授权。

只处理检索层标为可匹配、且实际返回原生字幕的候选。字幕缺失、处理中或不接受语言回退的候选不进入模型；没有可用证据时直接返回，不消耗推理请求。蓝图旧格式中缺少的预计投入、完成依据，以及未提供的学习起点、约束，都保留为未知。

模型只得到当前节点要求、可选学习背景、候选元信息与字幕摘录。整份蓝图、其他目标、任务 ID、平台观看／点赞数和凭据不进入提示。标题、描述使用长度受限的摘要；字幕最多选取贯穿首尾的 24 个原始片段，每段最多 320 个 Unicode 字符，保留原索引和毫秒时间。结果记录原片段数、抽样数和字幕文字是否被截断；这不是全片审阅。

模型数据提示上限为 96 KiB，超限在推理前拒绝，不静默删除节点要求。每项判断须引用同一视频、实际提供片段中的一到两段连续原文；未抽中的字幕即便存在于完整响应中，也不能成为本次引用。运行器自行补入时间，不接受模型编造时间戳。

## Skill 与输出控制

应用固定加载 [match-resources/v1/SKILL.md](../apps/web/src/lib/agent/skills/match-resources/v1/SKILL.md)，记录版本和正文 SHA-256；调用者可要求指定校验值，不匹配时不推理。用户内容不能选择 Skill 文件或切换版本。

所有节点、学习背景、视频描述和字幕都是数据，而不是可改变角色、权限或输出协议的指令。Skill 要求根据节点具体要求判断内容、保留未知、解释备选差异；不会把新旧程度、热度、搜索顺序或字幕存在等同于教学质量。

运行器检查所有可用候选恰好出现一次、推荐角色关系、真实候选 ID、引用原索引与原文、字段数量和文本长度；拒绝额外评分字段及显式链接文本，不从不合法答案中拼凑“部分成功”。全部拒绝与缺少证据是两种不同结果。摘要和判断仍属模型推断；前端接入时必须作为不可信内容安全渲染，不能因这些检查而允许任意 HTML 或导航。

推理复用已有 AI SDK `ToolLoopAgent` 策略：一次生成、无工具／重试、60 秒期限、取消和迟到输出保护、关闭普通输入／输出遥测、脱敏错误及真实 token 用量。模型由调用者显式提供；本批没有新增启用开关或读取环境密钥。返回依据指纹、检索时刻、来源修订、Skill 版本与抽样覆盖情况，便于后续记录审阅依据；这些不是认证凭据或实时播放保证。
