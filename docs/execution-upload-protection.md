# Agent 执行入口的有界上传

更新：2026-09-10；固定点 `8610f85`，实现提交 `854cfa6`。本地 P3/P6/P7 防护增量，不增加模型功能、权限或消费。

## 已实现行为

目标规划、目标澄清、资源检索／匹配／采用三个 Web 执行入口共用[请求体读取模块](../apps/web/src/lib/http/read-bounded-json.ts)。慢速客户端不能无限拖住读取，也不能靠持续发送零碎内容重新计时。

| 入口 | 实际字节上限 | 读取期限 |
| --- | --- | --- |
| 规划 | 2 KiB | 读取阶段共五秒 |
| 澄清 | 64 KiB | 读取阶段共五秒 |
| 资源 | 32 KiB | 读取阶段共五秒 |

按实际读取字节计量，不信任 Content-Length。分块 UTF-8 正确拼接，无效编码和 JSON 不作静默修补；客户端中断时及时退出，不继续进入额度预留或推理。超过体积返回 413，达到应用读取期限返回 408，空内容、非法格式或中断返回 422；错误正文仅包含固定分类，继续使用 `private, no-store`。输入流自身的同名错误不能冒充应用的截止期限。

失败后尽力取消流，但不等待可能永远不完成的发送方清理。读取锁、定时器和中断监听在正常完成与失败时释放。五秒只约束正文读取阶段，不声称完整认证、网络或 Agent 执行也在五秒内完成；既有执行期限和幂等规则不变。

## 认证与 Next 代理

三个入口都在路由自身校验同源、Cookie 身份、内容类型和账号归属，再读取配置、预留次数和执行；拒绝 Bearer 或跨账号替换。共享模块不承接身份、额度或模型职责。

真实生产 HTTP 先复现：资源入口按期返回，但规划和澄清均超过测试的十五秒上限。既有 Next 代理会等请求体结束，路由内的期限因此无法生效。现将[代理匹配](../apps/web/src/proxy.ts)的原资源特例扩展到三个精确执行地址，由已有路由认证自行验证与刷新 Cookie；未取消认证，也没有排除整个 `/api` 前缀。相邻地址、其他 API 和页面行为不变。

- [公开路由行为](../apps/web/src/lib/http/execution-upload.test.ts)使用实际 Request、ReadableStream、Supabase SDK，只替换外部 HTTP 与 Cookie 系统输入；覆盖中断、逐字节上传、精确上限、伪造长度、格式错误、涓流绝对期限和独立身份保护。
- [共享读取](../apps/web/src/lib/http/read-bounded-json.test.ts)核对中文／Emoji 分块还原、期限分类、锁与定时器释放，以及不完成的取消行为。
- [框架匹配测试](../apps/web/src/proxy.test.ts)使用当前安装的 Next 测试工具检查精确地址、尾斜杠、查询参数与相邻路径，不用自写正则替代框架判断。
- [真实生产 HTTP](../apps/web/resource-e2e/entry.spec.mts)用临时本地 Auth 账号、生产 Next 和数据库测试三个停滞上传；同时检查三类运行记录为空、提供方调用为空。资源成功链与双主题采用旅程也回归通过。提供方使用回环响应夹具，不是真实服务质量验收。

真实本地账号的规划生成／审阅／确认两条旅程，以及双主题澄清两条旅程均通过。资源启用模式六项通过；关闭模式四项通过、两项明确跳过启用旅程。账号由夹具退出并清理，无邮件或真实用户额度变更。70 节点规划旅程出现一次 Gzip `MaxListenersExceededWarning`，测试通过但原因未定，不据此宣称内存／性能门槛通过；后续性能核查保留该观察。
