# 资源执行入口与服务端边界

更新：2026-09-10；固定点 `74f473e`。P6/P7 本地增量：生产构建的 Web 接口、独立资源 worker 与现有持久运行层已经接通。功能默认关闭；没有启用真实提供方、修改托管配置或开放推荐页面。

## 本批结果

已登录账号可以明确请求一次检索、继续读取已保存的字幕任务，或匹配已完成的字幕证据。Web 只返回运行编号与状态；完整结果仍保存在账号隔离的运行记录中。重复请求恢复原操作，不新增外部调用；这些建议不修改正式路径，也不自动采用视频。

```text
已登录 Web 请求
  → Node：校验身份、输入与配置，预留账号次数
  → Edge：核验用户令牌和独立服务凭据，领取一次执行权
  → Node：固定提供方检索／字幕读取／匹配
  → Edge：保存原样结果回执
  → 账号隔离的运行记录
```

Node 使用原有实际 YouTube／Supadata 适配器、官方 DeepSeek SDK 和版本化匹配 Skill。Edge 只执行固定的领取与保存操作；管理员密钥仅留在 Supabase，不进入 Web 服务或浏览器。详见[持久运行与费用边界](agent-resource-runs.md)。

## 配置与安全边界

- 独立开关 `BLUEPRINT_RESOURCES_ENABLED` 默认关闭，不继承澄清或规划的启用状态。需要服务端模型、YouTube、Supadata 和独立 worker 凭据全部有效才开放执行。
- worker 凭据至少 32 字符，不能复用模型、提供方、公开 Supabase 或已配置的其他 worker 密钥；配置示例只包含空值。次数默认仍为零，启用配置不等于给用户发放消费额度。
- Web 接口仅接受同源、Cookie 登录的明确 POST 请求，拒绝 Bearer、账号替换、客户端字幕任务／证据、额外字段和无效编码。请求体按实际字节限制为 32 KiB，读取超时为 5 秒；失败只返回脱敏结果且不缓存。
- 资源接口单独绕过通用会话代理，自己验证与刷新 Cookie 登录。原因是当前 Next.js 代理会等待请求体结束，导致路由中的读取期限无法约束慢速上传；其他路由的代理行为保持不变。
- Edge 独立验证令牌签名、当前用户与会话，拒绝匿名账号、扩展 OAuth、伪造令牌和跨账号操作。关闭网关自动 JWT 检查不意味着公开特权写入；处理器仍要求用户令牌和专用服务凭据同时成立。
- 候选、字幕、Skill 与匹配结果在 Edge 有严格字段和容量边界；来源、租约与幂等由数据库保护，完整语义和字幕引用校验由 Node 负责。不宣称这些结构检查能证明教学质量。
- 匹配 Skill 明确进入生产文件追踪；测试提供方替身只在隔离测试进程加载，不提供可供用户选择的代理地址、模型或“模拟成功”模式。

## 运行证据

[实际 HTTP 联调](../apps/web/resource-e2e/entry.spec.mts)使用临时本地 Auth 账号，经过生产 Next.js → 实际 Supabase Edge → PostgreSQL。第三方响应由回环 HTTP 服务替代，模型响应仍经过官方 SDK 解析；没有真实提供方消费。

已验证三步执行、原请求重复提交不额外调用、默认零次数拒绝、正式路径版本不变、缺少／错误服务凭据、真实令牌篡改与跨账号拒绝。关闭功能时，即使账号和输入有效，也不创建运行记录或调用提供方。无效 UTF-8、超过字节上限与未结束上传均有实际 HTTP 检查。

慢速上传先复现为超过 15 秒未返回，定位到 Next.js 代理的请求体收尾等待；限定资源路由不经过该代理后，同一测试在读取期限后返回 408，且记录与外部调用均为空。这不是靠延长测试超时规避问题。

复现入口：`npm run test:resource-entry`；加 `BLUEPRINT_RESOURCE_ENTRY_TEST_DISABLED=true` 验证关闭分支。通过 `scripts/with-m1-runtime.sh` 使用已安装的本地工具，`BLUEPRINT_SUPABASE_BIN` 指向本机 Supabase CLI。测试拒绝托管地址，临时账号会退出并删除，不使用真实用户额度或浏览器任务空间。

整体回归、客户端产物隔离与两轴独立复核结果在本批完成后补记；不能将先前批次的测试数量当作本批结果。
